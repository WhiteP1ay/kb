# 被动收入

## 是什么

变富有的关键是拥有尽快将劳动性收入（工资）转换成被动收入或投资组合收入的能力。真正的财富自由不是高薪，而是资产产生的现金流覆盖全部支出。

## 关键点

- 劳动性收入 → 被动收入 / 投资组合收入：这是致富的核心转换
- 财富的定义：停止工作后能活多久
- "只要支出控制在资产项产生的现金之下，就会越来越富有"
- 3 年左右收回投资成本是一个好的参考标准
- 真正的富人先构筑资产项，再用资产收入买奢侈品——顺序不能反

## 陷阱

- 高薪 ≠ 财富——高薪只是高税率的劳动性收入
- 中产阶级模式：赚钱 → 买房 → 更大的房贷 → 更努力赚钱 → 更多支出
- "穷人有一些不好的习惯，其中一个就是随便动用储蓄"——储蓄应创造收入，而非支付账单
