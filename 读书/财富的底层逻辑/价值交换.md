# 价值交换

## 是什么

人与人之间最本质、最忠诚的关系不是情感，而是价值交换。社会通过利益交换来运转——你能为他人创造多少价值，决定了你能获得多少回报。

## 关键点

- 人际关系本质 = 价值交换
- 认识大佬本身没有用，你能提供什么价值才有用
- 真正有资源的人反而远离无效社交
- 赚钱的本质是为社会/他人提供了有价值的产品或服务

## 陷阱

- 沉迷社交、混圈子、加微信——但没有可交换的价值，认识谁都没用
- 倒贴式社交在真正有资源的人眼里是减分项
- 以为“我认识某某”等于自己变厉害了——纯自嗨
