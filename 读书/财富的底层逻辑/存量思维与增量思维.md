# 存量思维与增量思维

## 是什么

存量是你现在手里的钱，增量是你未来还能赚到的钱。穷人的思维盯着存量——我有多少花多少；富人的思维盯着增量——我花的钱能带来多少未来的回报。

## 关键点

- 存量 = 现有的资产和资金
- 增量 = 未来可预期的收入和增长
- 穷人倾向即时性消费（买衣服、买包）
- 富人倾向投资性消费（买课程、买资产）
- 确保价值大于价格是基本准则

## 陷阱

- 用存量思维做决策，永远跳不出月光的循环
- 认为涨工资就能变宽裕——不改变思维，涨多少都不够
- 被免费的东西吸引=在用存量思维衡量价值
