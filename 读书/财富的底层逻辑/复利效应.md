# 复利效应

## 是什么

复利不只是金融概念——复利金钱收获财富，复利知识收获智慧，复利运动收获健康，复利情感收获幸福。选对方向后坚持住前期的痛苦与平庸，爆发点在拐点之后。

## 关键点

- 复利可应用于6个维度：金钱、知识、运动、快乐、情感、生活
- 竹子定律：前4年只长3cm，第5年每天30cm
- 选对方向后坚持前期的痛苦与平庸
- 大目标拆解为季度→月→周→日的可执行小目标
- 持续接近目标，而非一步到位

## 陷阱

- 在拐点到来前放弃——大多数失败都死在黎明前
- 追求立竿见影——复利的前半段几乎看不到成果
- 方向错了还坚持——复利的方向比速度重要得多
- 只关注金钱复利，忽视认知和能力复利
