# 本体与开悟

## 是什么

本体（Being）是超越所有生命形式而永在的“至一生命”，是你最深的自我的未显化的生命。开悟就是重新觉知到本体并保持这种觉知的状态——与生命及它所显化的世界合一，与本体合一。你不是你的思维，你远比思维更伟大。

## 关键点

- 本体超越生死，是永恒的生命本源
- “我是”的真谛只能在临在状态中领会
- 开悟 = 与本体合一的圆满状态
- 在肉身看似与众生分离的表象下，你与万物合一
- 你的本质超越生和死

## 陷阱

- 把“开悟”当成一个未来的目标去追求——它只能在当下发生
- 用思维去理解“本体”——本体超越概念，只能被体验到
- 认为开悟需要特殊条件——它只是一种简单的与本体合一的自然状态
