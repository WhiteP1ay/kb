# 觉性

## 是什么

全书最核心的一句话：有“觉”即是禅修，无“觉”则不是禅修。觉性不是你需要创造的东西——它本自具足，你只是需要认出它。禅修就是在一切动静中保持“觉”，带着觉性生活。所谓开悟，不是得到什么新东西，而是认识自己本来的心性。

## 关键点

- 有觉即是禅修，无觉不是禅修——就这么简单
- 觉的三个层次：觉察（注意到六识活动）→ 觉观（观察念头情绪生住灭）→ 觉照（安住觉性本身）
- “不怕念起，就怕觉迟”——念头来了不是问题，不知道来了才是问题
- 能觉 = 觉察的能力，所觉 = 觉察的对象——不要把注意力黏在所觉上
- 自己的心性\觉性是最终极的上师

## 陷阱

- 把“觉”当成一个需要用力维持的状态——觉性是放松的、自然的
- 只在禅修垫上修觉性——“带着觉生活”才是真正的修行
- 用大脑去“找”觉性——言语道断，心行处灭，觉性超越思维
