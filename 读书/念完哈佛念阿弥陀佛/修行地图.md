# 修行地图

## 是什么

陈宇廷给出了藏传佛教噶举派清晰的修行次第：四共加行（思维人身难得、生死无常、业报因果、轮回皆苦）→ 四加行 → 止观 → 本尊法 → 大手印。这不是一条线性的路，更像是一个螺旋——每一次循环回到“觉性”这个核心，但越来越深。

## 关键点

- 四共加行：人身难得、生死无常、业报因果、轮回皆苦——生起出离心
- 四加行：皈依大礼拜、金刚萨埵、献曼达、上师相应法——净障积资
- 止观：止（专注）和观（洞察）——核心禅修技术
- 本尊法：与观音菩萨相应=心中生起无量慈悲
- 大手印：直指心性——最终的目标
- “悟后起修，才是真修”——先认出觉性，再在生活中稳定它

## 陷阱

- 执着次第本身——地图不是目的，最终要放下地图
- 跳过基础直奔大手印——没有出离心和菩提心的“大手印”是空中楼阁
- 比较宗派——“黄教重视经教，白教重视禅修”不是谁好谁坏，是适合不同根器
