# 觉性科学

## 是什么

陈宇廷最大的贡献是用现代语言翻译佛学概念：“色即是空”就是爱因斯坦的质能互换；禅修不是宗教，是认识心和意识运作模式的科学方法；咒语像调频器，用音波频率调整脑波；世界是“调频的结果”——修行是调整自己这台接收器。

## 关键点

- 色不异空 = E=mc²——质能互换，物质和能量是同一回事
- 禅修 = 静心→认识自心→体验心性本质的科学方法
- 咒语 = 音波频率调频器——调整脑波到平和、慈悲、智慧
- 脑不再不由自主收发信息时，能接收的不只是五感范围
- 左手和右手一体——左右手的比喻同时解释了同理心和空性
- “皈依”=走上认识自心之旅，不是崇拜外在对象

## 陷阱

- 把“科学”当成新的权威——科学解释是为了让人信服，不是取代体证
- 以为理解了概念就等于证到了——知道质能互换和亲证空性是两回事
- 过度追求“科学验证”——有些体验超越当前科学的测量范围
