# 【露丝的魔法3】打开心

## 是什么

露丝的第三招魔法——也是“终极魔法”：除非先把心敞开，否则无法得到真正想要的东西。通过回忆和传递无条件的爱，让心从防御走向连接。慈悲不是大脑产生的——慈悲来自于心。

## 关键点

- 回忆一个曾无条件爱过你的人，感受那份温暖和接纳
- 将这份爱传递给关爱的人→无好恶感的人→有矛盾的人
- 看到伤害别人的人内心也受了很重的伤
- 心受伤的时候正是它能打开的时候
- 大脑影响心脏，心脏也同样影响大脑、情绪和决策

## 陷阱

- 跳过自己——先被爱、感受爱，才能传递爱
- 强迫自己原谅——不是原谅，是看到对方和自己一样不完美
- 只在练习时才打开心——真正的改变发生在日常生活中待人接物时
