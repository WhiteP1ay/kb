# 咒语（Mantra）是什么

## 是什么

Mantra = man（心） + tra（工具/保护）。咒语的本质是心的工具——通过重复念诵来收摄散乱的心念。

## 关键点

- 咒语不翻译：汉字是梵文音译，古代译经师故意不意译
- 力量在于音声本身的振动和专注力，不在于文字含义
- 念咒三要素：专注（耳朵听自己的声音）、持续（固定数量形成节奏）、信心（不一边念一边怀疑）
- 发音不绝对标准没关系，不同地区传承发音略有不同
