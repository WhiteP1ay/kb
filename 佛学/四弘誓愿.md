# 四弘誓愿

## 是什么

众生无边誓愿度，烦恼无尽誓愿断，
法门无量誓愿学，佛道无上誓愿成。

## 关键点

- 大乘佛教徒的入职宣言，任何汉传寺院早晚课都会念
- 递进逻辑：利他 → 自净 → 学习 → 终极目标
- 帮人的前提是自己要干净，自己干净的方法是学习，学习的终点是成佛
