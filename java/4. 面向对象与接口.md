# 面向对象与接口

Java 是严格的强类型面向对象语言。继承决定了“你是什么”，而接口决定了“你能做什么”。

## 1. 继承与 `super` 构造链

Java 只支持单继承（一个类只能有一个亲爹）。**子类实例化的第一件事，必须先让父类就位**：

- 子类构造函数第一行如果不写，编译器默认自动塞入隐式的 `super()`。
- 如果父类没有无参构造函数，子类必须显式手动传参调用 `super(args)`。
- 重写方法必须带上 `@Override` 注解，让编译器严格校验方法签名，防止拼写手抖。

```java
public class VipUser extends User {
    private final int level;

    public VipUser(String name, int level) {
        super(name); // 1. 必须在第一行调用父类构造完成基类初始化
        this.level = level;
    }

    @Override
    public void printRole() {
        System.out.println("VIP Level: " + level);
    }
}
```

## 2. 抽象类 vs 接口

| 维度 | 抽象类（Abstract Class） | 接口（Interface） |
| :--- | :--- | :--- |
| **本质定位** | **is-a（血统继承）**：核心业务骨架与状态共享 | **can-do（契约规范）**：外挂能力与行为标准 |
| **继承限制** | **单继承**（只能 `extends` 一个父类） | **多实现**（可以 `implements` 无数个接口） |
| **状态变量** | 可以拥有普通的成员变量（有状态） | 只能有 `public static final` 常量（无状态） |
| **默认实现** | 可以有普通实现方法 | Java 8+ 支持 `default` 默认实现方法 |

```java
// 接口定义契约：谁实现谁就要会 pay()
public interface PaymentGateway {
    void pay(BigDecimal amount);

    // default 方法：提供可选的默认实现，子类按需重写
    default void refund(BigDecimal amount) {
        System.out.println("默认暂不支持退款");
    }
}
```

核心铁律：优先使用接口（面向接口编程）实现解耦；子类构造第一行永远先让父类就位（`super`）；继承只用于强复用，接口用于广泛约定。
