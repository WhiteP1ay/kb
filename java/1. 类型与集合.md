# 类型与集合

Java 将数据严格区分为**栈内存里的裸数据（基本类型）与堆内存里的对象指针（包装类型）**。集合框架是承载这些对象的数据容器。

## 1. 基本类型 vs 包装类型

- **基本类型（Primitive）**：`int`, `long`, `double`, `boolean`, `char`。直接在栈内存存数值，快且省内存，**绝不能赋为 `null`**（类成员默认 0/false）。
- **包装类型（Wrapper）**：`Integer`, `Long`, `Double`, `Boolean`, `Character`。堆内存里的对象指针，未初始化可为 `null`。
- **自动拆箱 NPE(`NullPointerException`) 暗坑**：把可能为 `null` 的包装类直接赋值给基本类型时，隐式调用 `intValue()` 会抛空指针！Java 编译器会在很多把 Integer 当 int 用的场景偷偷把`Integer` 转换成 `int`（暗中调用 `.intValue()`）

```java
// 读 Map 或 DTO 时，若可能为空，局部变量一律用包装类，判空再拆箱
Integer count = map.get("unknown"); // 安全：拿到 null
int safeCount = count == null ? 0 : count;
```

## 2. 同一性 `==` vs 等价性 `.equals()`

- **`==` 比地址**：两个变量是否指向**同一块堆内存**。
- **`.equals()` 比内容**：两个对象内部的**数据逻辑值是否相等**。

```java
// 字符串与对象比值，永远用 .equals()；字面量放前面可安全防 NPE
"admin".equals(role); // 即使 role 为 null 也能安全返回 false，不抛 NPE

// ⚠️ IntegerCache 缓存池暗坑：-128 ~ 127 范围内的数值命中缓存，== 返回 true；超出则返回 false
Integer a = 1000, b = 1000;
a == b;        // ❌ false（超出缓存，堆中两块独立内存）
a.equals(b);   // ✅ true（逻辑值相等）
```

## 3. 常用集合（List / Map / Set）

Java 集合不能放基本类型（只认 `List<Integer>`，不认 `List<int>`），读写全靠成员方法：

```java
// 1. List：有序列表，方法取值
List<String> list = new ArrayList<>();
list.add("apple");
String first = list.get(0); // 严禁用中括号 list[0]

// 2. Map：键值对，词频统计一行流
Map<String, Integer> map = new HashMap<>();
map.put("key", map.getOrDefault("key", 0) + 1); // 存在则累加，不存在设为 1

// 3. Set：自动去重
Set<String> uniqueTags = new HashSet<>(list);
```

不用原生数组是因为 java 原生数组长度不可变，不能自动扩容。

为啥左边是  List ，右边是 new ArrayList。因为这是面向接口编程，左边是声明需要列表能力，右边是具体实现该能力的干活类，不一定是 ArrayList，也可以是别的。

核心铁律：对象比值必用 `.equals()`（字面常量放前防 NPE）；包装类读写注意隐式拆箱空指针；集合读写全走成员方法。
