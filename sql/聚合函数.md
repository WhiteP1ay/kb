# 聚合函数：把一堆值压成一个值

## 是什么

吃一组行、吐一个值的函数。常用的有 `count`、`sum`、`avg`、`min`、`max`。它们只在分组语境里有意义，配 [[GROUP-BY分组聚合]] 或整表不分组时使用。

## 怎么用

```sql
select sum(quantity * price) from order_items;
```

表达式写在聚合函数**里面**，先算每行的值，再把它们加起来。

## 关键点

- **聚合对象必须先算对**，否则聚合函数会把错的数加起来。order_items 里 `price` 是这一件的单价，不是这一行的金额；「总销售金额」要写 `sum(quantity * price)`
- 两个错误写法对照：`sum(price)` 是单价之和，`sum(quantity) * sum(price)` 是两个总数相乘，都不是总额
- `count(*)` 数所有行，`count(列)` 只数那一列非 NULL 的行，两者结果可能不同
- `count(distinct 列)` 数去重后的个数

## 陷阱

- 看列名想语义：金额类需求先确认表里存的是单价还是小计，映射不上就先算出来
- `sum` 返回 NULL 当没有任何行匹配（不是 0），要 0 得用 `coalesce(sum(x), 0)`
- `avg(整数列)` 在 PostgreSQL 里返回 numeric 精确值，别按整数除法预期
