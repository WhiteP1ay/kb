# 单表查询与逻辑

## SELECT 查询骨架与执行顺序

SQL 查询必须严格按照固定子句顺序书写，书写顺序与执行顺序不可颠倒。

```sql
SELECT user_id, sum(total) AS spent   -- 5. 投影与计算
FROM orders                            -- 1. 数据来源
WHERE created_at >= '2026-08-01'       -- 2. 原始行过滤
GROUP BY user_id                       -- 3. 分组压缩
HAVING sum(total) > 200                -- 4. 聚合后过滤
ORDER BY spent DESC                    -- 6. 排序
LIMIT 10 OFFSET 0;                     -- 7. 截断分页
```

- 分页公式：第 N 页为 `LIMIT 页大小 OFFSET (N - 1) * 页大小`。
- 去重：`SELECT DISTINCT city FROM users`，作用于整行投影组合。

## 运算符优先级：AND 高于 OR

SQL 里 `AND` 优先级高于 `OR`。多条件组合时必须用圆括号包裹独立逻辑单元。

```sql
-- 必须显式加括号，否则 AND 会优先与相邻条件结合造成静默错
SELECT * FROM orders
WHERE (user_id = 12 AND total = 10.00)
   OR (user_id = 13 AND total = 20.00);
```

- 最佳实践：只要 AND 与 OR 混用，永远显式加括号；单列多值优先用 `WHERE user_id IN (12, 13, 14)`。

## NULL 三值逻辑

SQL 逻辑是三值的：`true` / `false` / `unknown`。NULL 表示未知，参与任何常规比较结果都是 unknown，而 `WHERE` 只放行 true。

```sql
-- NULL 不能比，只能 is
SELECT * FROM products WHERE price IS NULL;
SELECT * FROM products WHERE price != 50 OR price IS NULL; -- 排除50但保留未定价
```

- 口诀：**NULL 不能用等号比，只能用 IS NULL 或 IS NOT NULL**。
- `price = NULL` 语法合法但永远查不出任何行。
