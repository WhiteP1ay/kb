# CSS 居中方案汇总

## 是什么

水平居中、垂直居中、水平垂直居中——不同场景不同方案。核心是理解每种方案的适用条件。

## 关键点

- 水平居中：`text-align: center`（行内/文本）、`margin: 0 auto`（块级定宽）、flex `justify-content: center`
- 垂直居中：`line-height` = height（单行文本）、flex `align-items: center`
- 水平垂直居中（万能）：flex + `justify-content: center` + `align-items: center`
- 绝对定位方案：`position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%)`
- Grid 方案：`place-items: center` 一行搞定
