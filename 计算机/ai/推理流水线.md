# 推理流水线（Inference Pipeline）

## 是什么

LLM 收到 prompt 后生成回答的完整过程：tokenize → forward → 采样 → 解码，循环直到结束符。类比：浏览器收到 HTML 后的 解析 → 渲染 流程。

## 关键点

- tokenize：自然语言拆成 token（中文一个字可能拆成多个 token，prompt 变「贵」）
- forward：神经网络算出下一个 token 的完整概率分布（每个候选词一个概率，总和=1）。最重的一步，attention 在这里决定「谁重要」
- 采样：按概率「掷骰子」选一个 token——高概率更常被选中，低概率偶尔也会中。下一个 token 在这里被决定；temperature 控制骰子偏斜
- 解码：选中的 token 变回文字，接回输入，循环
- 自回归：每生成一个 token 都依赖前面所有 token（含自己刚生成的）
- 推理时模型不联网、不查库——「知识」全在权重里（[[Training vs Inference]]）

## 陷阱

- 生成过程没有「检索/相似度」步骤——余弦相似度是 [[RAG]] 向量库的事，别混进流水线
- 同一 prompt 两次输出可能不同：采样随机性，不是 bug
- 「关键词权重高」只是 attention 的方向感，细节见 [[Attention]]
