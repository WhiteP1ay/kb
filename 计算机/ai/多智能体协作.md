# AI Agent 设计模式：多智能体协作

## 是什么

不再一个 Agent 包揽，按角色拆分：顺序型链式传递、分层型管理者协调（最稳定）、去中心化辩论投票。代表框架：AutoGen、MetaGPT、CrewAI。

## 关键点

- AutoGen：AssistantAgent 推理 + UserProxyAgent 执行工具，支持人类介入
- MetaGPT：为软件公司建模——PM 写 PRD→架构师出设计→工程师写代码
- CrewAI：定义 Agent+Task+Crew，一句 kickoff() 执行
- 辩论模式：3-4 个 Agent 互评收敛到更准答案
- 共享记忆：向量数据库、消息队列、共享数据库
