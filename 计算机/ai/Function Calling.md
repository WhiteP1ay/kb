# Function Calling（函数调用 / 工具调用）

## 是什么

模型不直接调 API，而是输出结构化意图（如 {"action":"查天气","city":"北京"}），你的代码解析后执行真实动作。

## 关键点

- 治「只会说不会做」：给模型手
- 模型是嘴，function calling 把嘴说的话变成手干活
- 依赖结构化输出（schema 约束参数）

## 陷阱

- 「决定调哪个工具」和「实际执行」是两段，执行在你自己的代码里
