# AI Agent 设计模式：工具使用（Tool Use）

## 是什么

LLM 通过调用外部 API、数据库、计算引擎突破自身能力边界。三代演进：Prompt Injection→Function Calling(结构化)→MCP(标准化协议)。

## 关键点

- Function Calling：模型输出 tool_calls JSON，系统端执行，可靠到可以上生产
- MCP：Anthropic 提出的 JSON-RPC 2.0 标准化协议，list_tools + call_tool 两端点
- 工具很多时用双编码器方案：工具描述向量化→语义相似度选 top-k
- 关键：错误重试机制、权限对齐用户、动态工具创建需沙箱隔离
