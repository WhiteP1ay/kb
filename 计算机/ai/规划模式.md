# AI Agent 设计模式：规划（Planning）

## 是什么

Agent 在执行前分解子目标。三种范式：ReAct（推理与行动交织，最主流）、Plan-and-Solve（先计划后执行）、Tree of Thoughts（多点探索选最优）。

## 关键点

- ReAct：Thought→Action→Observation 循环，灵活有反馈闭环，可能陷入局部最优
- Plan-and-Solve：先生成完整计划再执行，适合长程任务，避免短视
- ToT：每步展开多个候选+评价函数+BFS/DFS，适合数学证明、策略游戏
- 任务分解：LLM 作调度器，子任务交给专门模型/工具
