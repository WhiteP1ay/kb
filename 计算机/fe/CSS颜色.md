# CSS 颜色表示方法

## 是什么

命名颜色、HEX、RGB/RGBA、HSL/HSLA、currentColor 五种方式。

## 关键点

- 命名颜色：`red`、`blue` 等 140+ 种（包括 `transparent`）
- HEX：`#ff0000`、`#f00`（简写）
- RGB/RGBA：`rgb(255, 0, 0)`、`rgba(255, 0, 0, 0.5)`
- HSL/HSLA：色相(0-360)+饱和度+明度，更符合直觉调色
- `currentColor`：继承当前元素的 color 值，减少重复定义
