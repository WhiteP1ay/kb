# 原型继承与类继承的区别

## 是什么

ES6 class extends 是原型继承的语法糖——本质仍然基于原型链。class 定义的 methods 自动放 prototype 上，extends 内部帮你做了 Object.create 等操作。

## 关键点

- 原型继承三步：call 继承属性 → Object.create 继承方法 → 修复 constructor
- class/extends 编译后就是上面的三步
- class 只是写法更清晰，不改变 JS 的原型继承本质
