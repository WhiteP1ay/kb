# CSS 包含块

## 是什么

包含块是元素尺寸和位置百分比计算的参考系。不是指直接的父元素，而是根据定位方式决定的祖先元素。

## 什么是 padding 区

CSS 盒模型从外到内：margin → border → padding → content。**padding 区 = border 内侧到 content 外侧之间的区域**。

对于 absolute 定位的元素，包含块是最近的非 static 定位祖先的 padding 区，这意味着：

```
┌─────────────────────────────┐
│  margin                      │
│  ┌─────────────────────────┐ │
│  │ border                   │ │
│  │  ┌─────────────────────┐ │ │
│  │  │ padding 区           │ │ │
│  │  │  left:0 top:0 从这里开始  │ │ │
│  │  │  ┌─────────────┐    │ │ │
│  │  │  │ content      │    │ │ │
│  │  │  └─────────────┘    │ │ │
│  │  └─────────────────────┘ │ │
│  └─────────────────────────┘ │
└─────────────────────────────┘
```

`left: 0; top: 0` 定位在祖先 border **内侧**，而不是从 content 区开始算。所以 absolute 的子元素可以覆盖到祖先的 padding 区域，但不会超出 border。

## 关键点

- static / relative：包含块是最近的块级祖先的 **content 区**
- absolute：包含块是最近的非 static 定位祖先的 **padding 区**
- fixed：包含块是**视口**
- `width: 50%` → 相对于包含块宽度的 50%
- `top: 50%` → 相对于包含块高度的 50%
