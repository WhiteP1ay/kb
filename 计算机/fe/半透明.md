# CSS 半透明实现

## 是什么

三种方式实现半透明：opacity（整体透明）、rgba/hsla（单属性透明）、transparent 关键字。

## 关键点

- `opacity: 0.5`：元素整体透明（包括子元素），值 0~1
- `rgba(255, 0, 0, 0.5)` 或 `hsla(0, 100%, 50%, 0.5)`：只影响当前属性，子元素不受影响
- `transparent`：等同于 `rgba(0, 0, 0, 0)`，常用于 border/background
- opacity 会创建层叠上下文，可能影响 z-index 表现
