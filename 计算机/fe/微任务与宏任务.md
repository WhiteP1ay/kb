# 微任务与宏任务（任务优先级）

## 是什么

浏览器不止一条消息队列。微队列（Promise.then/MutationObserver）优先级最高，每次执行完一个普通任务后立即清空所有微任务。

## 关键点

- 微队列：Promise.then、MutationObserver —— 优先级最高
- 交互队列：用户事件处理 —— 浏览器知道用户等不起
- 延迟队列：setTimeout/setInterval —— 多等几毫秒用户感觉不到
- W3C 已不再使用「宏任务」这个词，只说「微任务」和「任务」
- 执行顺序：同步代码 → 清空微任务 → 下一个任务 → 清空微任务 → ...
