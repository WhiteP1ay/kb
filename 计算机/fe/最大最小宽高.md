# CSS 最大最小宽高

## 是什么

`min-width`、`max-width`、`min-height`、`max-height` 限制元素尺寸范围。优先级：min > max > width（当冲突时 min 胜出）。

## 关键点

- 响应式常用：`max-width: 100%` 防止图片超出容器
- 冲突时 min-width 优先级高于 max-width 和 width
- `min-height: 100vh` 让容器至少占满视口高度
- 与 flex/grid 配合时有特殊行为（如 flex 子项的 min-width 默认为 auto）
