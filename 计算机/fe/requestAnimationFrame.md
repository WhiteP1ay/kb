# requestAnimationFrame（rAF）

## 是什么

有自己独立队列——在微任务执行完毕、渲染更新前执行。专为在下一次重绘前更新动画设计，自动匹配屏幕刷新率。

## 关键点

- 执行时机：微任务 → rAF → 渲染
- 与 setTimeout 动画的区别：rAF 自动匹配刷新率（60fps → 16ms/帧），不会掉帧
- rAF 在页面不可见时自动暂停，节省 CPU 资源
- 做动画用时间差计算比依赖回调次数更精确
