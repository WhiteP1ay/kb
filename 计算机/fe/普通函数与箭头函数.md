# 普通函数与箭头函数的区别

## 是什么

核心差异在 this 绑定：普通函数 this 动态（看调用方式），箭头函数 this 在定义时固定（继承外层作用域）。其余差异都是衍生后果。

## 关键点

- 箭头函数：this 继承定义时上下文，无 arguments，不能 new，无 prototype，不能 yield
- 普通函数：this 动态，有 arguments，可 new，有 prototype，可 yield
- 箭头函数适合：回调、事件处理需要继承外层 this 的场景
- 不能用箭头函数的场景：对象方法需要 this 指向对象、构造函数
