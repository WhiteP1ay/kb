# 前端工程化中的图片处理

## 是什么

从压缩格式、懒加载、CDN 三个维度优化，进阶用 `<picture>` 标签做自动格式选择和响应式图片。

## 关键点

- 压缩：优先 WebP（比 JPEG 小 25-35%）
- 懒加载：`<img loading="lazy">` 浏览器原生支持
- CDN：静态资源走 CDN 边缘节点加速
- `<picture>` + `<source>` 组合：浏览器从前往后匹配，优先 WebP，回退 JPEG
- 可以根据 media query 加载不同尺寸的图片（响应式图片）
