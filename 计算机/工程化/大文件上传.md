# 大文件上传方案

## 是什么

文件分片+断点续传+秒传。核心流程：创建文件→分片哈希校验→并发上传→合并。优化：用户无需等哈希计算完即可开始上传。

## 关键点

- 四个协议：创建文件（HEAD 换 token）、哈希校验（秒传/断点续传）、分片上传、合并
- 并发控制：维护发送队列，并发 3-6 个，避免浏览器卡顿
- 存储去重：分片与文件解耦，独立记录；分片永不删除避免重复上传
- 合并优化：不真合并成大文件，生成 URL，下载时用流管道依次读分片
- Web Worker 计算哈希避免 UI 阻塞
