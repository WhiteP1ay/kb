# 事件循环 Event Loop

## 是什么

渲染主线程的调度机制——无限循环取消息队列里的任务执行，取不到就等待。所有异步代码最终都靠它调度。单线程 → 需要异步 → 事件循环是实现异步的方案。

## 关键点

- 主线程是个死循环：每次循环取一个任务执行
- 其他线程（交互、网络、定时器）往消息队列里塞任务
- 同步阻塞后果：主线程被占，后续任务全排队等待——页面卡死
- 这也是为什么「同步阻塞很可怕」
