# 回流（Reflow）与重绘（Repaint）

## 是什么

回流是重新计算几何信息（位置、大小），重绘是重新画外观（颜色等）。回流必触发重绘，重绘不一定触发回流。

## 关键点

- 触发回流：改宽高、改位置、增删 DOM、改字体、读 offsetHeight/scrollTop 等
- 触发重绘：改颜色、背景、阴影等不影响几何的属性
- 浏览器优化：批量处理回流，JS 跑完统一做一次
- 强制同步回流：JS 中读 offsetHeight 等布局属性时浏览器必须立刻回流
- 优化：读写分离（批量读→批量写）、用 class 替代逐条 style、用 transform 做动画
