# 类的继承

## 是什么

`class 子类(父类):` 的括号是**继承语法**，声明父类。无括号的 `class X:` 是 `class X(object):` 的简写（object 是所有类的根）。

## 怎么用

```python
class Student(TypedDict):   # Student 继承 TypedDict，获得「dict 形状定义」能力
    name: str
    score: int

class Shape(ABC):           # 继承抽象基类，获得「抽象接口约束」能力
    ...
```

## 关键点

- 等于 TS 的 `class X extends Y`
- 特殊基类模式：TypedDict、ABC 都是靠继承一个基类获得特定能力
- 子类继承父类的属性和方法

## 陷阱

- 别把括号想成「给 class 传参」，它是声明「我的父类是谁」
