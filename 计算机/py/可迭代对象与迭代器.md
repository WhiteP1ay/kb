# 可迭代对象与迭代器

## 是什么

可迭代对象（iterable）是能够传给 `iter()` 并返回迭代器的对象。

迭代器（iterator）是能够通过 `next()` 逐个产生元素，并保存当前遍历位置的对象。

| 类型 | 主要职责 | 常用操作 |
| --- | --- | --- |
| iterable | 提供遍历入口 | `iter(iterable)` |
| iterator | 保存遍历状态并逐个取值 | `next(iterator)` |

列表、元组、字符串、字典、集合和 `range` 都是常见的可迭代对象。可迭代与是否支持索引无关，例如集合没有位置索引，但仍然可以创建迭代器。

## 从可迭代对象创建迭代器

```python
numbers = [10, 20, 30]
iterator = iter(numbers)

print(next(iterator))  # 10
print(next(iterator))  # 20
print(next(iterator))  # 30
```

列表负责保存元素，本身不保存某一次遍历走到哪里；迭代器负责保存这次遍历的当前位置。

因此列表可以传给 `iter()`，但不能直接传给 `next()`：

```python
numbers = [10, 20, 30]

iter(numbers)  # 可以创建迭代器
next(numbers)  # TypeError
```

## 独立的遍历位置

同一个可迭代对象可以创建多个相互独立的迭代器：

```python
numbers = [10, 20, 30]

a = iter(numbers)
b = iter(numbers)

print(next(a))  # 10
print(next(a))  # 20
print(next(b))  # 10
```

`a` 和 `b` 读取同一个列表，但各自保存自己的遍历位置，所以 `b` 的第一次取值仍然是 `10`。

## 迭代器会被消费

迭代器取出的元素不会自动恢复。元素耗尽后，再次遍历不会输出任何内容：

```python
numbers = [10, 20]
iterator = iter(numbers)

for number in iterator:
    print(number)

for number in iterator:
    print(number)
```

输出：

```text
10
20
```

第二个循环没有输出。迭代器耗尽时会发出 `StopIteration`，`for` 捕获这个信号后直接结束循环，不会输出 `None`。

再次遍历原来的列表则会创建一个新的迭代器：

```python
for number in numbers:
    print(number)
```

输出：

```text
10
20
```

## for 如何工作

下面的代码：

```python
for number in numbers:
    print(number)
```

底层逻辑可以近似理解为：

```python
iterator = iter(numbers)

while True:
    try:
        number = next(iterator)
    except StopIteration:
        break

    print(number)
```

`for` 自动创建迭代器、重复取值，并在迭代器耗尽时结束循环。

## 与 JavaScript 的对应

JavaScript 的可迭代对象通过 `[Symbol.iterator]()` 创建迭代器：

```javascript
const numbers = [10, 20, 30]
const iterator = numbers[Symbol.iterator]()

iterator.next()
```

Python 中对应的是：

```python
numbers = [10, 20, 30]
iterator = iter(numbers)

next(iterator)
```

两种语言都把“数据来源”和“某一次遍历的当前位置”分开。Python 的 `for...in` 在用途上更接近 JavaScript 的 `for...of`。

## 容易混淆的点

- 支持索引和支持迭代是两种不同能力。
- iterable 可以创建 iterator，但不一定能直接使用 `next()`。
- iterator 保存遍历位置，并且会随着取值逐步被消费。
- 同一个列表创建出的多个迭代器拥有独立的遍历位置。
- 迭代器耗尽后，循环不会输出 `null` 或 `None`，而是直接结束。
- 有些对象既是 iterable，也是 iterator，例如生成器；具体实现留到“迭代器与生成器”章节。
