# 对象创建两阶段

## 是什么

Python 对象创建拆成两步：`__new__` 铸造、`__init__` 装修。JS 的 `new Foo()` 是原子操作，Python 拆开，且允许劫持"分配"本身。

## 怎么用

`__new__` 是类方法（第一参数 `cls`），负责返回实例；`__init__` 是实例方法（第一参数 `self`），负责填属性。

关键规则：`__new__` 返回的实例是 cls（或其子类）的实例 → 自动调 `__init__`；返回别的对象 → `__init__` 跳过。

## 关键点

- 默认 `__new__` = `object.__new__(cls)` 分配空实例
- 重写 `__new__` 忘写 `return super().__new__(cls)` → 返回 None → `__init__` 不执行，属性全无
- `__init__` 每次走创建流程都执行——单例也逃不掉

## 陷阱

- 双下划线是名字的一部分：`__new__` ≠ `new`，丢了就不是魔术方法（不报错，静默失效）
- `__init__` 不是构造器，"造"是 `__new__` 的活，`__init__` 只是装修
