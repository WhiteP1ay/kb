# 乘方与异或

## 是什么

Python 三个跟"乘"沾边的运算符，完全不是一回事：

```text
n *  2    # 相乘
n ** 2    # 幂（n 的 2 次方）→ 平方
n ^  2    # 按位异或，跟平方无关
```

## 陷阱

数学里平方写成上标 n²，代码里没有上标，习惯性地写成 `n^2` 就踩坑了：

```python
{n**2 for n in nums}   # {1, 4, 9, 16, 25}  正确：平方
{n^2  for n in nums}   # {0, 1, 3, 6, 7}    错误：异或
```

`^` 是 bitwise XOR（二进制逐位"相同得 0、不同得 1"），`1 ^ 2 = 3`、`2 ^ 2 = 0`。

## 关键点

JS 和 Python 一样：`^` 都是异或，指数在两边都是 `**`。这不是语言差异，是数学记号漏进了代码。
