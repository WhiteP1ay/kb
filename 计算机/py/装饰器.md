# 装饰器：从闭包到 @ 语法糖

## 是什么

接受一个函数、返回一个新函数的高阶函数。不改函数内部代码，给它穿一层外套（横切逻辑：计时、日志、鉴权、重试）。前端对应：React HOC（`withAuth(Component)`）、Koa/Express 中间件。骨架就是闭包：wrapper 通过闭包捕获外层参数 func。

## 怎么用

手工版与 @ 等价：

```python
from functools import wraps
import time

def timer(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"耗时 {time.time() - start:.4f}s")
        return result
    return wrapper

@timer
def fetch_data(url):
    ...
# @timer 等价于 fetch_data = timer(fetch_data)
```

带参数装饰器：三层结构，外层收参数、中层收函数、内层收调用：

```python
def max_retry(max_times):            # 第 1 层：收参数
    def decorator(func):             # 第 2 层：收函数（真正的装饰器）
        @wraps(func)
        def wrapper(*args, **kwargs):# 第 3 层：收调用
            for i in range(max_times):
                try:
                    return func(*args, **kwargs)
                except Exception:
                    if i == max_times - 1:
                        raise
        return wrapper
    return decorator
```

## 关键点

- `@timer` 在函数定义完的那一刻执行，等价 `f = timer(f)`
- 应用顺序自下而上（离函数最近的先包，成内层），执行顺序从外往里（最外层 wrapper 先跑）——先包的后执行，像洋葱
- 传函数对象不带括号：`@timer` 和 `@timer()` 是两个东西，后者先调用拿配置（带参数形态）
- 每写装饰器都加 `@wraps(func)`，把原函数 `__name__`/`__doc__` 拷到 wrapper，否则框架靠函数名干活时全乱

## 陷阱

- 忘 `return wrapper` → 函数变 None，调用报 `TypeError: 'NoneType' object is not callable`
- 忘 `return result` → 原函数返回值被吞，所有被装饰函数返回 None
- `greet(name)` 是调用结果（None），`greet` 才是函数对象——装饰器传函数，别传调用
- 三层结构每层 return 丢一个就崩；`@repeat` 写成 `@repeat(3)` 才带参，混了会报缺参
