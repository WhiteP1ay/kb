# 推导式的边界

## 是什么

推导式只做三件事：映射、过滤、去重。超出这三件事，推导式就不该用。

## 什么时候不用推导式

聚合累加（group by 求和/计数）必须用 `for` 循环 + `result.get`：

```python
result = {}
for o in orders:
    uid = o["user_id"]
    result[uid] = result.get(uid, 0) + o["amount"]
```

关键：读旧值从 `result`（累加目标），读新值从 `o`（当前数据）。

## 关键点

- 硬把聚合拗成推导式，代码会又长又难读
- 真正的能力不是"知道推导式怎么写"，是"知道什么时候不用推导式"
