# Python 真值规则

## 是什么

Python 的条件表达式不要求结果已经是 `bool`。对象用于 `if`、`while`、`and`、`or` 或 `not` 时，解释器会判断它的真值（truthiness）。

可以使用 `bool()` 显式查看一个对象的真值：

```python
print(bool([]))   # False
print(bool([1]))  # True
```

## 常见假值

```python
False
None
0
0.0
""
[]
{}
()
set()
```

它们分别代表布尔假值、空值、数值零、空字符串和空容器。其他普通对象通常为真。

```python
print(bool("0"))   # True
print(bool([0]))   # True
print(bool({"id": 0}))  # True
```

字符串 `"0"`、包含零的列表和非空字典都不是空对象，因此为真。

Python 的布尔值写作 `True` 和 `False`，首字母必须大写。小写的 `true` 和 `false` 会被当作普通名字。

## 条件中的用法

```python
tasks = []

if tasks:
    print("存在任务")
else:
    print("没有任务")
```

不必写成：

```python
if len(tasks) > 0:
    print("存在任务")
```

直接利用容器的真值通常更符合 Python 惯用写法。

## 与 JavaScript 的区别

JavaScript 中的空数组 `[]` 和空对象 `{}` 都是真值；Python 中的空列表 `[]` 和空字典 `{}` 都是假值。

```python
print(bool([]))  # False
print(bool({}))  # False
```

因此，把依赖 JS truthiness 的条件直接翻译成 Python 时，要重新检查空容器的行为。

## 容易混淆的点

- `None` 是 Python 的空值，不是 `null`。
- `True` 和 `False` 必须大写。
- 空容器是假值，非空容器通常为真。
- 字符串 `"0"` 为真，数值 `0` 为假。
- 自定义对象也可以定义自己的真值规则，具体机制留到类和魔术方法章节。

## 闭卷自测

```python
print(bool(""))
print(bool("0"))
print(bool([]))
print(bool([0]))
print(bool(None))
```
