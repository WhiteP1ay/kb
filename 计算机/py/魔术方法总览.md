# 魔术方法：双下划线协议

## 是什么

Python 里名字带双下划线（`__x__`）的方法叫魔术方法（dunder method），是对象与 Python 语法的「协议接口」。语法糖操作对象时自动调用对应方法：

```python
print(obj)          # → __str__
obj == other        # → __eq__
obj()               # → __call__
obj.attr            # → __get__（描述符）
```

不写 = 用默认行为（大多难看或不是想要的）；写了 = 定制操作。不是元编程——元类控制「类」本身的创建（meta），魔术方法定制「对象」的日常操作，层级不同。

## 怎么用

在类里按需定义。`__init__`（构造）就是最常见的魔术方法。

## 关键点

- 语法糖自动触发，不需要手动调用
- 方法名查表，不能发明：`__lt__`/`__le__`/`__gt__`/`__ge__` 对应 `<`/`<=`/`>`/`>=`
- JS 类比：`toString`、`valueOf`、`Symbol.iterator` 等约定方法

## 陷阱

- 名字拼错（如 `__lg__`）→ 方法不被调用，报 `'<' not supported`，静默失效比报错更阴
- 双下划线 ≠ 私有，只是命名约定
