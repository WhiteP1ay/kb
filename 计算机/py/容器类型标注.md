# 容器类型标注

## 是什么

list/dict 等容器参数的现代类型标注写法（Python 3.9+ 内置泛型），替代 3.9 之前的 `typing.List` / `typing.Optional` 老写法。

## 怎么用

```python
def f(ids: list[int]) -> None: ...
def g(m: dict[str, int]) -> None: ...

# 联合类型（3.10+；3.9 用 Union[int, float]）
def h(x: int | float) -> float: ...

# 嵌套从外到内读：list，元素是 dict，key 是 str，value 是 int 或 float
def total(orders: list[dict[str, int | float]]) -> float: ...
```

## 关键点

- 一律**方括号**：`list[int]`、`dict[str, int]`，不是 TS 的 `Array<int>`
- 不是老写法 `List[int]`、`Optional[str]`
- `int | float` 联合类型需要 Python 3.10+；macOS 系统 python3 是 3.9.6 会报错，uv 项目环境（3.12+）没问题

## 陷阱

- **漏掉容器层**：`students: Student` 应为 `list[Student]`。若真传单个 dict，`for s in students` 遍历的是 key 字符串，`s["score"]` 崩 string indices must be integers
- **返回值标 int 实为 float**：`sum(...) / len(...)` 是 float（`/` 真除法，`90 / 2` = `45.0`）。TS 的 number 通吃，Python 严格分 int/float
