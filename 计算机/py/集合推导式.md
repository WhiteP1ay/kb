# 集合推导式

## 是什么

用花括号 + 无冒号的表达式生成一个集合，自动去重：

```python
{n**2 for n in nums}   # nums 里有重复元素也不怕
```

## 与字典推导式的区别

`{}` 里看有没有冒号：

```text
{w.upper() for w in words}    # 无冒号 → 集合推导式（去重）
{w: len(w) for w in words}    # 有冒号 → 字典推导式
```

## 关键点

集合自带去重，结果无序。适合"提取不重复的值"的场景。
