# 单例模式

## 是什么

全局唯一实例。Python 里靠重写 `__new__` 实现：唯一状态放类属性，`__new__` 里判断拦截。

## 怎么用

class Singleton:
    _instance = None
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

## 关键点

- 唯一性状态必须放类属性（跨实例共享），放实例属性则每次创建都重置
- `a = Singleton(); b = Singleton()` → `a is b` True；但 `__init__` 每次都执行
- 初始化逻辑写在 `__init__` 里会反复执行 → 加 `_initialized` 标志或搬进 `__new__`

## 陷阱

- `self.singleton = None` 写在 `__init__` 里不会破单例（判断用的是 `cls.singleton`），但语义混乱
- 类属性持有实例引用 → del 名字不销毁，对象活到类被回收
- `_instance` 判断逻辑若放实例层面，每次 `__init__` 重置，单例必破
