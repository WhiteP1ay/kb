# == 与 is

## 是什么

`==` 比较两个对象的值是否相等；`is` 比较两个操作数是否引用同一个对象。

```text
==：value equality，值相等
is：object identity，对象身份相同
```

## 值相等

```python
a = [1, 2]
b = [1, 2]

print(a == b)  # True
```

`a` 和 `b` 是两个不同列表，但内容相等，所以 `==` 返回 `True`。

`!=` 表示值不相等：

```python
print(a != b)  # False
```

## 对象身份相同

```python
a = [1, 2]
b = [1, 2]
c = a

print(a is b)  # False
print(a is c)  # True
```

`c = a` 没有创建新列表，只是让 `c` 也绑定到 `a` 所绑定的对象。

`is not` 表示不是同一个对象：

```python
print(a is not b)  # True
```

## 检查 None

`is` 最常见的正确用途是检查 `None`：

```python
if value is None:
    print("没有值")
```

对应的非空判断是：

```python
if value is not None:
    print("存在值")
```

## 不要用 is 比较字符串和数字

```python
value is 10       # 错误用法
name is "Asuka"   # 错误用法
```

解释器可能复用某些小整数或字符串对象，使结果偶尔看起来正确，但对象复用不是值比较契约。比较字符串、数字和普通业务值应使用 `==`。

## 与 JavaScript 的区别

JavaScript 中两个内容相同但独立创建的数组使用 `===` 比较会得到 `false`：

```javascript
[1, 2] === [1, 2] // false
```

Python 列表的 `==` 比较内容，因此：

```python
[1, 2] == [1, 2]  # True
```

Python 的 `is` 可以帮助理解为“是否为同一个对象”，但不要把它机械等同于所有场景下的 JavaScript `===`。

## 容易混淆的点

- `==` 比较值，`is` 比较对象身份。
- `c = a` 只增加一个名字绑定，不会复制对象。
- 检查 `None` 使用 `is None` 或 `is not None`。
- 字符串、数字和普通业务值使用 `==`，不要使用 `is`。
- 值相等不代表是同一个对象。

## 闭卷自测

```python
a = [1, 2]
b = [1, 2]
c = a

print(a == b)
print(a is b)
print(a is c)
```

1. 三行分别输出什么？
2. 如果修改 `c` 指向的列表，为什么 `a` 也会看到变化？
