# 字典推导式

## 是什么

用一行表达式从可迭代对象生成字典：

```python
{w: len(w) for w in words}
# {'asuka': 5, 'shinji': 6, 'rei': 3}
```

冒号左边是 key，右边是 value。

## 对比 JavaScript

JS 写同样的事要 `Object.fromEntries` 或 `reduce`，Python 一行搞定：

```javascript
Object.fromEntries(words.map(w => [w, w.length]))
```

## 关键点

- 和集合推导式的唯一区别：多一个冒号
- 冒号左边是键表达式，右边是值表达式
