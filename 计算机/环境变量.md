# 环境变量

## 是什么

环境变量是操作系统传给进程的一组键值。`PATH` 是其中一个，它记录了查找可执行文件的目录，目录之间用冒号 `:` 分隔。

```text
/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin
```

在终端输入命令时，shell 会按从左到右的顺序，在这些目录中寻找同名的可执行文件。找到后便停止搜索并执行它。因此，同一个命令可能因为 `PATH` 顺序不同而运行不同的程序。

```bash
# 查看 PATH
echo "$PATH"

# 查看命令最终指向哪里
command -v python
command -v python3
```
