# HTTP 版本演进（0.9 → 1.0 → 1.1 → 2 → 3）

## 是什么

HTTP/0.9 仅文档；1.0 引入请求头/响应头/状态码；1.1 持久连接/管道化/队头阻塞；2 多路复用/二进制/HPACK；3 基于 QUIC/UDP 彻底解决队头阻塞。

## 关键点

- 1.1 队头阻塞：同一连接请求必须按顺序处理，第一个卡住后面全等
- 2 多路复用：同一 TCP 连接并发多个请求/响应，但 TCP 层仍有队头阻塞
- 3 基于 QUIC(UDP)：每个流独立传输，丢包不影响其他流；内置 TLS 1.3
- 1.1→2 主要解决应用层队头阻塞，2→3 解决传输层队头阻塞
