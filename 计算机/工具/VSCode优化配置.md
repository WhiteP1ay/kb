# VSCode 专业配置

## 是什么

几行配置让 VSCode 更好用：文件树缩进指示器、Fira Code 连字字体、推荐主题（One Dark Pro/Dracula/GitHub Theme）。

## 关键点

- 文件树清晰：`workbench.tree.indent` + `renderIndentGuides` + 颜色定制
- Fira Code：符号连字（`=>` 显示为箭头），各平台安装方法见 README
- Material Icon Theme：更清晰美观的图标
