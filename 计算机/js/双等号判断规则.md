# == 运算符的判断规则

## 是什么

双等号在类型不同时触发隐式转换，有固定规则：Number==String 转数字，Boolean==Anything 转数字，null==undefined 互等。

## 关键点

- Number == String → String 转 Number
- Boolean == Anything → Boolean 转 Number
- null == undefined → 它们俩相等，且只彼此相等
- Object == Primitive → 对象通过 valueOf()/toString() 转原始值
- NaN == anything → 永远 false
- if(value) 判断逻辑与 == 不一致（if 不涉及隐式转换）
