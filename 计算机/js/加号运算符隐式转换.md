# + 运算符的隐式转换规则

## 是什么

任意一边是字符串 → 转字符串拼接；否则尝试转数字。一条规则覆盖所有情况。

## 关键点

- `'5' + 3` → `'53'`（字符串优先）
- `true + 1` → `2`（Boolean 转 Number）
- `null + 1` → `1`（null 转 0）
- `undefined + 1` → `NaN`（undefined 转 NaN）
- 对象 + 数字：先调 valueOf()，不行再 toString()
- `[] + {}` vs `{} + []` 是经典陷阱题
