# 闭包（Closure）

## 是什么

函数对外部作用域变量的引用，延长了作用域链——本质是函数加上它所记住的外部变量环境。

## 关键点

- 三大场景：封装私有变量、异步环境记住状态、函数工厂
- for(var i) 经典问题：var 没有块级作用域，用 IIFE 或 let 解决
- 函数工厂：createCounter 返回独立的计数函数，各自记住自己的 count
- 闭包 != 内存泄漏，但不当使用会导致变量无法被 GC 回收
