# 如何判断对象中存在循环引用

## 是什么

用 WeakSet 递归遍历对象属性，检测重复引用。JSON.stringify 遇到循环引用会抛错，可配合 try-catch 侧面检测。

## 关键点

- 核心算法：seen = new WeakSet()，递归遍历，遇到已见过的对象 → 循环引用
- 为什么用 WeakSet：不阻止 GC 回收遍历过的中间对象
- JSON.stringify 抛错侧面检测：不精确但一行代码
- 面试常问的递归遍历类问题
