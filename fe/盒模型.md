# CSS 盒模型

## 是什么

每个 HTML 元素都是一个矩形盒子。盒模型定义了元素内容、内边距（padding）、边框（border）、外边距（margin）的布局关系。

## 关键点

- 标准盒模型：`width` = content 宽度；总宽度 = content + padding + border + margin
- 替代盒模型（`box-sizing: border-box`）：`width` = content + padding + border，更直观
- 行内元素：width/height 无效，padding/margin 只影响水平方向（垂直方向不占空间）
- 行内块元素（`inline-block`）：兼具行内布局和块级盒模型
