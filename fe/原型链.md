# 原型链的指向关系

## 是什么

沿着 __proto__ 一路向上，直到 null，构成原型链——这是 JS 属性查找和继承的基础机制。

## 关键点

- dog.__proto__ → Dog.prototype
- Dog.prototype.__proto__ → Animal.prototype
- Animal.prototype.__proto__ → Object.prototype
- Object.prototype.__proto__ → null（原型链终点）
