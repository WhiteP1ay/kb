# 服务端缓存与取消（React 19）

## cache()：请求级记忆化去重

专为 React Server Components (RSC) 设计的记忆化函数。在**单次服务端渲染请求周期内**，相同参数的调用只真正执行一次，其余调用直接复用缓存结果。

```jsx
import { cache } from "react";

// 用 cache 包裹数据获取函数
export const getUser = cache(async (id: string) => {
  const res = await db.user.findUnique({ where: { id } });
  return res;
});

// 在多个平行组件中随意调用，整个 HTTP 请求期间只查一次数据库
async function Header({ userId }) {
  const user = await getUser(userId); // 第 1 次：走数据库查询
  return <div>{user.name}</div>;
}

async function Sidebar({ userId }) {
  const user = await getUser(userId); // 第 2 次：直接拿请求级缓存，不发查库
  return <div>{user.role}</div>;
}
```

- **作用域**：单次 HTTP 渲染周期。每次新请求进来都是全新干净的上下文，绝不会把 A 用户的私密数据串给 B 用户。
- **生态意义**：打破了 Next.js 对“魔改 fetch 自动去重”的黑盒垄断，将请求去重能力收拢下沉到 React 官方运行时，Remix / TanStack 等任何全栈框架均可无缝使用。

## cacheSignal()：生命周期绑定的取消机制

配合 `cache()` 使用。当用户在服务端数据还没取完就提前切走或中断连接时，向底层发出中止信号，防止无效请求持续占用服务器资源。

```jsx
import { cache, cacheSignal } from "react";

export const getHeavyReport = cache(async (date: string) => {
  // cacheSignal() 获取当前请求关联的 AbortSignal
  return fetch(`/api/report?date=${date}`, {
    signal: cacheSignal(), // 渲染中断时自动 abort 底层 fetch
  });
});
```

- **核心价值**：自动将外部请求的生命周期与 React 渲染管线挂钩，避免服务端死跑“僵尸网络请求”。
