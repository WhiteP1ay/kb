# Context API

## 是什么

Context 本质是「跨层传值工具」而非完整状态管理系统。
适合更新频率低、天然全局的值（主题、语言、用户）。
业务状态多了就要面对重渲染问题。

## 关键点

- Context 擅长：把值跨层传下去、让组件共享上层信息
- 不擅长：精细订阅、避免不必要重渲染、追踪状态变化
- 任何字段变化→所有消费者重渲染（设计取向，不是 bug）
- 优化：按职责拆分 Context、useMemo 稳定 value、不滥用升级局部状态
- Context vs 状态库：前者解决「值怎么传」，后者解决「谁该更新、谁不该」
