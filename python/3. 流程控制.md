## == 与 is

## 是什么

`==` 比较两个对象的值是否相等；`is` 比较两个操作数是否引用同一个对象。

```text
==：value equality，值相等
is：object identity，对象身份相同
```

## 值相等

```python
a = [1, 2]
b = [1, 2]

print(a == b)  # True
```

`a` 和 `b` 是两个不同列表，但内容相等，所以 `==` 返回 `True`。

## 对象身份相同

```python
a = [1, 2]
b = [1, 2]
c = a

print(a is b)  # False
print(a is c)  # True
```

`c = a` 没有创建新列表，只是让 `c` 也绑定到 `a` 所绑定的对象。

`is not` 表示不是同一个对象：

```python
print(a is not b)  # True
```

## 检查 None

`is` 最常见的正确用途是检查 `None`：

```python
if value is None:
    print("没有值")
```

对应的非空判断是：

```python
if value is not None:
    print("存在值")
```

## 不要用 is 比较字符串和数字

```python
value is 10       # 错误用法
name is "Asuka"   # 错误用法
```

解释器可能复用某些小整数或字符串对象，使结果偶尔看起来正确，但对象复用不是值比较契约。比较字符串、数字和普通业务值应使用 `==`。

## 链式比较

Python 支持接近数学写法的链式比较：

```python
x = 5

print(1 < x < 10)  # True
```

它表达的判断意图是：

```python
1 < x and x < 10
```

中间表达式只求值一次，这在中间位置是函数调用或有计算成本的表达式时尤其重要。

也可以连续判断相等：

```python
a = 10
b = 10
c = 10

print(a == b == c)  # True
```
## and、or 与 not

`and`、`or` 和 `not` 是 Python 的逻辑运算符;

它们对应 JavaScript 中的 `&&`、`||` 和 `!`，但 Python 和 JavaScript 对空容器的真值判断不同。

## or 返回什么

`or` 返回第一个真值操作数；如果所有操作数都是假值，返回最后一个操作数。

```python
print("" or "匿名用户")     # 匿名用户
print([] or ["fallback"])  # ['fallback']
print("ready" or "backup") # ready
```

## and 返回什么

`and` 遇到假值时返回该假值；如果所有操作数都是真值，返回最后一个操作数。

```python
print("" and 42)       # 空字符串
print("ready" and 42)  # 42
```

`and` 和 `or` 返回的是操作数本身，不保证返回 `bool`。

## not 返回什么

`not` 会先判断对象真值，然后返回相反的布尔值，所以结果一定是 `True` 或 `False`。

```python
print(not [])      # True
print(not [1, 2])  # False
```

## match..case

`match / case` 用模式检查一个值的结构，并且可以在匹配时从中取出数据。

`case` 后面写的是“模式”，模式既可以负责比较，也可以负责捕获数据。

```python
status = "open"

match status:
    case "open":
        print("已开启")
    case "closed":
        print("已关闭")
    case _:
        print("未知状态")
```

Python 从上到下检查各个 `case`，只执行第一个成功匹配的分支，没有 JavaScript `switch` 的贯穿执行。

`_`是通配符，负责兜底，只匹配不保存。

## 从结构中捕获数据

模式匹配的主要价值不是替代 `if / elif`，而是同时检查结构并取出数据。

```python
ticket = {
    "id": 42,
    "status": "closed",
}

match ticket:
    case {"id": ticket_id, "status": "open"}:
        print("已开启", ticket_id)
    case {"id": ticket_id, "status": actual_status}:
        print(ticket_id, actual_status)
```

第二个模式中：

- `"id"` 和 `"status"` 是要检查的字典键。
- `ticket_id` 捕获 `42`。
- `actual_status` 捕获 `"closed"`。

guard：捕获后增加条件

如果需要与一个已有变量的值动态比较，不能直接把该变量裸写在 `case` 中，应使用 guard：

```python
expected = "open"
status = "closed"

match status:
    case value if value == expected:
        print("匹配")
    case _:
        print("不匹配")
```

执行逻辑是：

1. `case value` 先捕获当前值。此时执行赋值操作，即 `value == 'closed'`。`match..case`没有独立作用域，所以在`match..case`外打印value是`'closed'`
2. `if value == expected` 再检查附加条件。所以打印"不匹配"

## 异常处理

唯一模板：

```python
try:
    result = func(*args, **kwargs)    # 可能出错的代码
except ConnectionError as e:          # 按类型接；as e 拿异常对象（≈ JS catch(e)）
    print("连不上:", e)
except Exception:                     # 兜底接所有
    ...
finally:                             # 无论如何都执行：资源清理
    ...
```
