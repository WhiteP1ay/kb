# 装饰器

## 装饰器本质

装饰器是一个**接收函数并返回新函数**的可调用对象，核心利用了闭包机制。

```python
def log_call(func):
    def wrapper(*args, **kwargs):
        print(f"调用前: {func.__name__}")
        result = func(*args, **kwargs)
        print(f"调用后: {func.__name__}")
        return result
    return wrapper

@log_call
def add(a, b):
    return a + b

# @log_call 等价于语法糖：add = log_call(add)
```

## 保留函数元信息：@functools.wraps

裸写装饰器会把原函数的属性替换为 wrapper 的属性（如 `add.__name__` 变成 `"wrapper"`，文档字符串失效）。必须在 wrapper 上加上 `@wraps(func)`：

```python
from functools import wraps

def log_call(func):
    @wraps(func)  # 复制原函数的 __name__、__doc__ 等元信息
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper
```

## 带参装饰器工厂（三层结构）

如果装饰器自身需要接收参数（如 `@repeat(num=3)`），需要外包一层函数工厂：

```python
from functools import wraps

def repeat(num: int):
    def decorator(func):       # 第二层：接收原函数
        @wraps(func)
        def wrapper(*args, **kwargs):  # 第三层：接收执行参数
            for _ in range(num):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(num=3)
def greet(name):
    print(f"Hello, {name}")
```

## 执行时机

- **定义期装载**：在 Python 导入/定义函数的那一刻，装饰器函数本身就会被执行并完成包装（不是等到函数被调用才包装）。
- **调用期执行**：后续每次调用被修饰的函数时，真正执行的是内部的 `wrapper`。
