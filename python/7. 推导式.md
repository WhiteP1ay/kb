# 推导式

用一行优雅表达式完成集合数据的处理，本质是对循环的精炼语法糖。

## 列表推导式

等价于 JavaScript 中的 `map` + `filter` 合体：

```python
words = ["asuka", "shinji", "rei"]
# [映射表达式 for 变量 in 可迭代对象 if 过滤条件]
long_words = [w.upper() for w in words if len(w) > 4]
# [ASUKA, SHINJI]
```

## 字典推导式

与集合推导式的唯一区别是表达式带有冒号 `key: value`：

```python
name_lengths = {w: len(w) for w in words}
# {asuka: 5, shinji: 6, rei: 3}
```

## 集合推导式

使用花括号且**无冒号**，结果自动去重且无序：

```python
nums = [1, 2, 2, 3, 3]
squares = {x ** 2 for x in nums}
# {1, 4, 9}
```

## 推导式的边界：何时不用推导式

推导式只做三件事：**映射、过滤、去重**。超出这三件事，绝对不要硬塞进推导式。

- **累加聚合 / 分组统计**：必须使用普通 `for` 循环搭配 `dict.get()`：
  ```python
  # 正确写法：清晰直白
  counts = {}
  for o in orders:
      uid = o["user_id"]
      counts[uid] = counts.get(uid, 0) + o["amount"]
  ```
- **核心准则**：硬把多步复杂逻辑拗成推导式是反模式。能让人一眼看懂的 `for` 循环远好于三层嵌套的推导式。
