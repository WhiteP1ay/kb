# 魔法函数

Python 里名字带双下划线（`__x__`）的方法叫魔术方法（dunder method），是对象与 Python 语法的「协议接口」。

```python
print(obj)          # → __str__
obj == other        # → __eq__
obj()               # → __call__
obj.attr            # → __get__（描述符）
```

## 打印

- `__str__`：给人类看（`print(obj)`）
- `__repr__`：给开发者看（REPL、日志、容器打印）
生产代码 `__repr__` 比 `__str__` 更重要（日志/REPL/容器全找它）

## 比较

`__lt__`/`__le__`/`__gt__`/`__ge__` 对应 `<`/`<=`/`>`/`>=`

```python
def __eq__(self, other):
    if not isinstance(other, Money):
        return NotImplemented
    return self._value == other._value

def __hash__(self):
    return hash(self._value)   # 与 __eq__ 用同一字段
```

## 对象创建

Python 对象创建拆成两步：`__new__` 铸造、`__init__` 装修。Python 拆开，且允许劫持。

`__new__` 是类方法（第一参数 `cls`），负责返回实例；

`__init__` 是实例方法（第一参数 `self`），负责填属性。
## 单例模式

实现全局唯一实例。
Python 里靠重写 `__new__` 实现：唯一状态放类属性，`__new__` 里判断拦截。

```python
class Singleton:
    _instance = None
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

```

## 对象销毁

`__del__` 是对象被回收前的钩子。

CPython 用引用计数：引用数归零 → 立即回收 → `__del__` 同步触发。

注意点：
- `del 名字` 只是减一个引用，不一定触发 `__del__`
- 解释器退出时清理也会兜底触发，但顺序不确定。执行时机不可控。

## 实例可调用

`__call__` 负责实例调用。

```python
class Greeter:
    def __init__(self, prefix):
        self.prefix = prefix

    def __call__(self, name):
        return f"{self.prefix}, {name}!"

hi = Greeter("你好")
hi("朴昊哲")   # '你好, 朴昊哲!'
```
