# 类与面向对象

## 类与实例基础

类定义共同的数据和行为，实例是根据类创建的对象。Python 创建实例不写 `new`。

```python
class User:
    def __init__(self, name: str):
        self.name = name  # 实例属性

    def greet(self) -> str:
        return f"Hello, {self.name}"

user = User("Anna")
user.greet()
```

- **`__init__` 与 `self`**：`__init__` 是初始化入口；`self` 指代当前实例（类似 JS 的 `this`），在定义实例方法时**必须显式写在第一个参数**，调用时由 Python 自动传入。

## 实例属性 vs 类属性与遮蔽

```python
class Ticket:
    status = "open"  # 类属性（所有实例共享）

    def close(self):
        self.status = "closed"  # 关键：给实例绑定同名属性，遮蔽类属性

a = Ticket()
b = Ticket()
a.close()

# a.status 为 "closed"，b.status 仍为 "open"，Ticket.status 仍为 "open"
```

- **查找机制**：先查实例自身同名属性，找不到才回退查找类属性。
- **可变类属性共享大坑**：类级列表、字典等可变对象在类加载时只有一份！
  ```python
  class Team:
      members = []  # 严重错误！所有 Team 实例将共享同一个列表
  ```
  每个实例独立的数据必须在 `__init__` 中初始化：`self.members = []`。

## dataclass：数据载体类

针对主要用于承载数据的类，使用 `@dataclass` 自动生成 `__init__`、`__repr__` 和按字段比较的 `__eq__`：

```python
from dataclasses import dataclass, field

@dataclass
class Ticket:
    title: str
    status: str = "open"
    # 可变字段必须使用 default_factory 生成独立对象，不能直接赋 []
    tags: list[str] = field(default_factory=list)

a = Ticket("Bug A")
b = Ticket("Bug A")
print(a == b)  # True：自动按字段值对比
```

## 类的继承

`class 子类(父类):` 括号内声明继承来源。无括号的 `class X:` 默认继承顶层根类 `object`。

```python
class Animal:
    def speak(self) -> str:
        return "..."

class Dog(Animal):
    def speak(self) -> str:
        return "汪汪"
```

## @property：属性访问守卫

将方法伪装成属性，读走 getter，写走 setter，用于参数校验与内部状态保护：

```python
class Money:
    def __init__(self, amount: float):
        self._amount = amount  # 约定：下划线前缀表示内部受保护变量

    @property
    def amount(self) -> float:
        return self._amount

    @amount.setter
    def amount(self, value: float) -> None:
        if value < 0:
            raise ValueError("金额不能为负")
        self._amount = value  # 严禁写 self.amount = value，否则引发无限递归死循环
```

## ABC 抽象基类：强制接口契约

约束子类必须实现指定方法。与 TypeScript 编译期检查不同，Python 的 ABC 在**实例化子类时由运行时强制检查**：

```python
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self) -> float: ...

    def describe(self) -> str:
        return f"面积是: {self.area()}"

class Circle(Shape):
    def __init__(self, r: float):
        self.r = r

    def area(self) -> float:
        return 3.14159 * self.r ** 2
```

- 若子类没有实现抽象方法，创建实例时直接抛出 `TypeError: Can't instantiate abstract class`。
