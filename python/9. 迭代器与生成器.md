# 迭代器与生成器

## 可迭代对象 vs 迭代器

Python 将“数据来源”和“遍历状态”彻底解耦：

| 类型 | 职责 | 核心协议方法 | 示例 |
| :--- | :--- | :--- | :--- |
| **可迭代对象 (Iterable)** | 存放数据，提供遍历入口 | 实现 `__iter__()` 返回迭代器 | 列表、字典、集合、字符串 |
| **迭代器 (Iterator)** | 保存当前游标位置，按需吐出下一个值 | 实现 `__next__()` 和 `__iter__()` | `iter([1, 2])`、生成器 |

```python
nums = [10, 20]
it = iter(nums)      # 创建迭代器（游标）

print(next(it))      # 10
print(next(it))      # 20
# print(next(it))    # 再次调用抛出 StopIteration 异常
```

- **迭代器会被一次性消费**：迭代器遍历完后无法重置，再次 `for` 循环直接跳过；想重新遍历必须从原始列表重新创建迭代器。
- **`for` 循环本质**：内部先调用 `iter()` 获取迭代器，不断调用 `next()`，捕获 `StopIteration` 信号后安全退出。

## 手写迭代器模板

```python
class CountDown:
    def __init__(self, start: int):
        self.current = start

    def __iter__(self):
        return self  # 自己作为迭代器

    def __next__(self) -> int:
        if self.current <= 0:
            raise StopIteration  # 边界耗尽，抛出终止信号
        val = self.current
        self.current -= 1
        return val
```

## 生成器（Generator）：惰性流式计算

带有 `yield` 关键字的函数就是生成器函数。调用它不会立即执行代码，而是返回一个生成器对象（既是 iterable 也是 iterator）。

```python
def read_large_file(file_path):
    with open(file_path, "r", encoding="utf-8") as f:
        for line in f:
            yield line.strip()  # 产出当前值，函数执行暂停并冻结上下文
```

- **极致省内存（O(1) 空间复杂度）**：一次只在内存中计算并保留一行数据，千万级大数据流式处理不爆内存。
- **生成器表达式**：使用圆括号表示惰性计算，不产生中间完整列表：
  ```python
  # 列表推导式（立刻全部求值占内存）
  total = sum([x * 2 for x in range(1000000)])

  # 生成器表达式（随取随算，内存无消耗）
  total = sum(x * 2 for x in range(1000000))
  ```
