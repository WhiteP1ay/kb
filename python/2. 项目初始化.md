## uv

暂时把 uv 理解成 pnpm

```bash
# 创建项目并指定解释器版本
uv init example --python 3.12
cd example

# 添加项目依赖，同时更新 pyproject.toml、uv.lock 和虚拟环境
uv add httpx

# 根据项目文件同步虚拟环境
uv sync

# 在项目虚拟环境中运行命令
uv run python

# 查看依赖树
uv tree
```

uv 项目有三类关键内容：

## pyproject.toml

声明项目元数据和依赖范围，类似package.json

```toml
[project]
name = "python-env-lab"
version = "0.1.0"
requires-python = ">=3.12"
dependencies = [
    "httpx>=0.28.1",
]
```

如果项目要被构建，可以指定构建器。

```toml
[build-system]
requires = ["uv_build>=0.11"]
build-backend = "uv_build"
```

- uv.lock：锁文件，类似 yarn.lock
- .venv 虚拟环境目录，类似 node_modules，但包含python 解释器。

## pyenv

pyenv 是 Python 版本管理工具，可以类比为 Node.js 生态中的 nvm。

```shell
# 安装某个版本
pyenv install 3.10.4

# 设置当前用户的默认版本
pyenv global 3.10.4

# 设置当前目录及其子目录使用的版本
# 该命令会在当前目录写入 .python-version
pyenv local 3.10.4

# 查看已安装版本，星号表示当前选中的版本
pyenv versions

# 查看当前版本及其选择来源
pyenv version
```
