# in 与链式比较

## in 成员检查

`in` 判断一个值是否属于某个容器或可迭代对象，结果为 `True` 或 `False`。

```python
print(5 in [1, 5, 9])   # True
print("py" in "python")  # True
```

`not in` 表示不属于：

```python
print(8 not in [1, 5, 9])  # True
```

## 字典默认检查键

```python
user = {"id": 7, "name": "Anna"}

print("id" in user)  # True
print(7 in user)     # False
```

对字典使用 `in` 时，默认检查键，不检查值。

常见 JavaScript 对照：

```text
列表 in：类似 Array.prototype.includes()
集合 in：类似 Set.prototype.has()
字典 in：检查是否存在对应的键
```

## 链式比较

Python 支持接近数学写法的链式比较：

```python
x = 5

print(1 < x < 10)  # True
```

它表达的判断意图是：

```python
1 < x and x < 10
```

中间表达式只求值一次，这在中间位置是函数调用或有计算成本的表达式时尤其重要。

也可以连续判断相等：

```python
a = 10
b = 10
c = 10

print(a == b == c)  # True
```

## 与 JavaScript 的区别

JavaScript 不能用下面的写法表达数学区间：

```javascript
1 < x < 10
```

JavaScript 会先计算 `1 < x`，得到布尔值，再拿该布尔值和 `10` 比较。正确写法是：

```javascript
1 < x && x < 10
```

Python 可以直接写：

```python
1 < x < 10
```

## 容易混淆的点

- `in` 是成员检查，结果一定是 `bool`。
- 字典的 `in` 默认检查键。
- 字符串的 `in` 可以检查子串。
- Python 支持链式比较，JavaScript 不支持相同语义。
- 链式比较的中间表达式只求值一次。
