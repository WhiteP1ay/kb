# 类型

Python 的类型标注（`x: int`、`-> str`）是写给工具和读代码的人看的**注释**。
CPython 解释器运行时完全无视。

```python
def f(x: int) -> str:
    return x * 2

f("hi")      # 返回 "hihi"，不报错。解释器只看 x * 2
```

## 容器类型标注

一律**方括号**：`list[int]`、`dict[str, int]`

```python
def f(ids: list[int]) -> None: ...
def g(m: dict[str, int]) -> None: ...

# 联合类型（3.10+；3.9 用 Union[int, float]）
def h(x: int | float) -> float: ...

# 嵌套从外到内读：list，元素是 dict，key 是 str，value 是 int 或 float
def total(orders: list[dict[str, int | float]]) -> float: ...
```

## TypedDict

给字典定义类型

```python
from typing import TypedDict

class Order(TypedDict):
    amount: int
    price: float

def total_price(orders: list[Order]) -> float:
    return sum(o["amount"] * o["price"] for o in orders)
```
