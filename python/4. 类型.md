# 类型系统

Python 的类型标注（`x: int`、`-> str`）是写给静态分析工具（mypy）和开发者看的**注释**。
CPython 解释器运行时完全无视，不自动做类型转换或校验。

```python
def f(x: int) -> str:
    return x * 2

f("hi")      # 返回 "hihi"，不报错。解释器只看表达式 x * 2
```

## 容器类型标注

一律使用**方括号**（Python 3.9+ 内置支持）：

```python
def f(ids: list[int]) -> None: ...
def g(m: dict[str, int]) -> None: ...

# 联合类型（3.10+ 用 |；旧版用 Union[int, float]）
def h(x: int | float) -> float: ...

# 嵌套标注：从外向内读
def total(orders: list[dict[str, int | float]]) -> float: ...
```

## TypedDict：字典形状契约

给 dict 的结构定义静态类型接口（类似 TypeScript 的 interface），保持普通 dict 运行特性的同时获得字段提示与拼写检查：

```python
from typing import TypedDict

class Order(TypedDict):
    amount: int
    price: float

def total_price(orders: list[Order]) -> float:
    return sum(o["amount"] * o["price"] for o in orders)
```

- **访问方式**：运行时仍然是普通字典，必须用 `o["amount"]`，不能用点号 `o.amount`。
- **定位**：TypedDict 只负责静态形状检查（防敲错 key），不做运行时校验，漏字段依然抛 `KeyError`。
