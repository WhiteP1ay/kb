# 类型标注与运行时

## 是什么

Python 的类型标注（`x: int`、`-> str`）是写给工具和读代码的人看的**注释**，CPython 解释器运行时完全无视。检查类型靠独立的静态检查器 mypy（= Python 的 tsc）。

## 怎么用

```python
def f(x: int) -> str:
    return x * 2

f("hi")      # 返回 "hihi"，不报错——解释器只看 x * 2
```

想检查类型，装 mypy 并运行：

```bash
mypy xxx.py
```

## 关键点

- `x: int = "hello"` 照跑不误，解释器不校验
- 类型标注喂给三类东西：IDE（VSCode Pylance 补全/悬停）、mypy（静态检查）、读代码的人
- 与 TS 的本质差异：TS 有编译期类型检查（tsc 报错），Python 没有编译期检查这回事，mypy 是你主动请来的

## 陷阱

- 别以为类型不匹配会抛 TypeError/SyntaxError——运行时不会，只有 mypy 会报
- 系统 macOS 自带 python3 是 3.9.6，标注语法版本敏感（见 [[容器类型标注]]）
