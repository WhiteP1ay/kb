# Pydantic 与响应模型

Pydantic 是 FastAPI 的核心数据引擎，兼具 TypeScript 静态类型提示与 Zod 运行时校验的双重能力。

## 出参白名单过滤（response_model）

在路由装饰器中指定 `response_model`，可实现严格的出参安全过滤：

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class UserCreate(BaseModel):
    username: str
    password: str

# 出参模型：只暴露公开安全字段
class UserResponse(BaseModel):
    id: int
    username: str

@app.post("/users/", response_model=UserResponse)
def create_user(payload: UserCreate):
    db_record = {
        "id": 101,
        "password_hash": "secret_hash_123",  # 内部敏感字段
        **payload.model_dump(),              # 转字典后解构合并
    }
    # FastAPI 会依据 response_model 自动将 password_hash 物理剥离，绝不外泄给前端
    return db_record
```

## Pydantic 与 Dict 转换规则

- **模型转字典**：必须调用 `payload.model_dump()`。
- **解构合并（类似 JS `{ ...obj, id }`）**：`{"id": 1, **payload.model_dump()}`。
- **原地合入更新**：`target_dict.update(payload.model_dump())`。

避坑铁律：Pydantic 模型不是字典，严禁使用 `payload["username"]`（报 TypeError）；给普通字典 update 时必须传入 `.model_dump()`。
