# 接口自动化测试

FastAPI 官方标准的接口自动化测试体系，由 **pytest**（测试运行器）与 **TestClient**（基于 ASGI 的内存客户端）配合组成（等价于前端生态的 Vitest + Supertest）。

## 核心测试用例编写

在 `test_main.py` 中编写用例：

```python
from fastapi.testclient import TestClient
from main import app, db_fake

client = TestClient(app)

# 夹具：每个测试函数执行前清空状态，杜绝测试间数据污染
def setup_function():
    db_fake.clear()

def test_api_workflow():
    # 1. 测试正常创建
    res = client.post("/todos", json={"title": "Test", "completed": False})
    assert res.status_code == 200
    assert res.json()["title"] == "Test"

    # 2. 测试 404 边界
    res_not_found = client.get("/todos/999")
    assert res_not_found.status_code == 404

    # 3. 测试 422 参数缺失校验拦截
    res_bad = client.post("/todos", json={})
    assert res_bad.status_code == 422
```

运行测试：
```bash
uv run pytest test_main.py
```

## 机制与最佳实践

- **零网络开销**：无需提前启动 Uvicorn，不监听任何真实端口。`TestClient` 基于 ASGI 协议在内存中直接调用应用函数，毫秒级跑完用例。
- **测试状态污染防护**：内存测试时，前一个用例插入的数据会常驻全局伪库中。务必使用 `setup_function()` 或 pytest fixture 在用例前清空测试数据。
