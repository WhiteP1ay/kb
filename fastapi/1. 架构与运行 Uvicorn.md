# 架构与运行 Uvicorn

## 厨师与服务生（解耦架构）

FastAPI 与底层网络服务器采用严格的 **ASGI（异步服务器网关接口）** 解耦架构：
- **FastAPI（后厨厨师）**：应用层框架，负责路由分发、类型注解解析、数据校验与业务处理。
- **Uvicorn（前台服务生）**：专职高性能网络服务器，底层基于 Node 同款的 **uvloop** 与 **httptools**，专职在操作系统层面监听 TCP 端口并收发网络数据包。

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "Hello World"}
```

- **启动命令**：没有 Node/Express 的 `app.listen()`，由命令行工具统一部署启动：
  ```bash
  uv run uvicorn main:app --reload
  # main: main.py 文件名；app: 实例化的变量名；--reload: 代码热重载
  ```
- **自动文档**：启动后访问 `/docs` 自动生成交互式 Swagger UI，数据源均为 `/openapi.json`。

## 同步与异步的分工铁律

- **`async def` 禁写同步阻塞**：若在 `async def` 里调用 `time.sleep(5)` 或同步数据库驱动，会直接卡死主事件循环，导致并发全军覆没。
- **普通 `def` 自动进线程池**：若有无法避免的同步耗时库（如裸 requests、文件读写），直接声明为普通函数 `def root():`，FastAPI 会自动将其放入内部独立线程池运行，绝不阻塞主循环。

最佳实践：纯异步 I/O 用 `async def`；含有同步阻塞代码或 CPU 密集计算直接用普通 `def` 交给线程池。
