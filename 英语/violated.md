# violated

## 音标
/ˈvaɪəleɪtɪd/

## 释义
违反，违背（法律/规则/协议）/ 侵犯（隐私/权利）

## 例句
Your account has been deactivated because recent activity violated our Terms and Usage Policies.

The API key was revoked because the client violated the rate limit policy — 10,000 requests per minute is not a suggestion.

## 记忆法
viol(力量，同 violence) + ate → 施加强力 → 侵犯/违背

## 同义词
breached, infringed, broke, transgressed
