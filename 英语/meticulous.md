# meticulous

## 音标
/məˈtɪk.jə.ləs/

## 释义
adj. 一丝不苟的，极其仔细的（对细节的关注近乎偏执）

## 例句
She keeps meticulous records of every API change — three years of commit logs, never missed a single one.

A meticulous code reviewer will catch that missing semicolon and the off-by-one error in the same pass.

## 记忆法
源自拉丁 metus（恐惧），原意是"胆小怕事的"，后来语义漂移成"因为怕出错所以极度仔细"。从"恐惧"到"一丝不苟"的语义演变——就像那种怕合并冲突所以把 diff 一行行看完的谨慎。

对比 [[rigorous]]：rigorous 是标准层面的严格（方法、流程）；meticulous 是执行层面的仔细（人的态度、习惯）。

## 同义词
painstaking, scrupulous, thorough, precise, careful
