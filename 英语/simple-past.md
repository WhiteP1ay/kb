# 一般过去时 (Simple Past)

## 结构

### 肯定句
主语 + 动词过去式 + 其他

- 规则动词：动词原形 + -ed (worked, played, started)
- 不规则动词：需要单独记忆 (go → went, see → saw, write → wrote, run → ran)

> 提醒：不规则动词没有统一规律，建议遇到一个记一个。常用的大约 100 个左右。

### 否定句
主语 + did not (didn't) + 动词原形 + 其他

```
I didn't see that bug yesterday.
She didn't commit the code on time.
```

> 注意：否定句中动词恢复原形，因为 did 已经承担了过去时态。

### 疑问句
Did + 主语 + 动词原形 + 其他？

```
Did you fix the memory leak?
Did the build pass last night?
```

## 用法

1. 过去某个时间点完成的动作
   强调动作发生在过去，与现在没有直接联系。适合描述"昨天发生了什么"、"上次上线出了什么问题"。
   ```
   I pushed the wrong branch to production last Friday.
   The server crashed at 3 AM and nobody noticed.
   ```

2. 过去连续发生的动作序列
   描述一系列按时间顺序发生的过去事件，比如排查问题的过程。
   ```
   I checked the logs, found the error, and rolled back the deployment.
   ```

3. 过去的习惯或状态
   以前经常做但现在已经不做的事情。常与 used to 互换，但一般过去时更简洁。
   ```
   We used PHP for everything back then. (= 那会儿我们啥都用 PHP)
   I wrote all my notes in plain text files before discovering Obsidian.
   ```

4. 在条件句 (if) 中表示假设
   与现在事实相反的假设，虽然形式上是一般过去时，但表达的是现在的不现实情况。
   ```
   If I had more time, I would refactor the entire codebase.
   ```

## 例句

```
Yesterday I deployed to prod without running the tests first. Nothing broke, but I aged five years.

Last week our CI pipeline was down for two hours because someone force-pushed to main.

I learned Vim in 2018 and never looked back.
```

## 关键词/标志词

以下时间状语经常与一般过去时搭配：

- yesterday (昨天)
- last night / last week / last month / last year
- ... ago (two days ago, a year ago)
- in 2020 / in June (已经过去的某个时间点)
- just now (刚才)
- when I was ... (当我……的时候)
- the other day (前几天)
