# rigorous

## 音标
/ˈrɪɡ.ər.əs/

## 释义
adj. 严格的，严密的，缜密的（尤指过程或方法）

## 例句
The paper underwent rigorous peer review before publication.

A rigorous code review catches bugs that linters miss — no shortcuts.

## 记忆法
rigor（严格）+ ous（形容词后缀）= 像僵硬的尺子一样毫不通融 → 严格的，缜密的。rigor 源自拉丁语"僵硬"，对比 rigor mortis（尸僵）。

## 同义词
strict, thorough, meticulous
