# ship

## 音标
/ʃɪp/

## 释义
v. ① 上线，发布（软件/产品）；② 运送，发货

在软件开发中，"ship" 指把代码/功能/产品交付给用户，强调「做完就推、不再纠结」的执行力。源自「把货物装船运出去」，引申为「把产品送到用户手里」。

## 例句
We're shipping the new API endpoint tomorrow — tests are green, let's go.

We need to ship this feature before the sprint ends, even if it's not perfect. (自造句)

## 记忆法
字面义「船 → 装船运走」→ 软件语境下「代码上船 → 推送给用户」。口诀：**代码装上船，推送不等闲。** 区别于 deploy（纯技术操作），ship 带有决策意味——拍板说「发吧」。

## 同义词
deploy, release, launch, deliver
