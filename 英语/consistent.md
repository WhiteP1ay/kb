# consistent

## 音标
/kənˈsɪstənt/

## 释义
adj. 一致的，始终如一的；连贯的

## 例句
She has been consistent in her performance all year.

Consistent code style matters more than which style you pick. *(自造句)*

## 记忆法

### 词根
> con- (together 共同) + sist (站立) + -ent (形容词后缀) → 站在一起的 → 一致的

### 谐音
> —

## 同义词
steady, uniform, constant, coherent
