# __name__ 双身份

## 是什么

Python 文件有「双身份」：要么是脚本，要么是模块，取决于怎么运行。直接运行 `python main.py` 时 `__name__ == "__main__"`（脚本，无包身份）；被 import 时 `__name__` 是模块全名（如 `"shop.cart"`）。`if __name__ == "__main__":` 是入口守卫，区分两种身份。

## 怎么用

```python
if __name__ == "__main__":
    # 只有直接运行这个文件时才执行这里
    # 被 import 时跳过——测试代码不污染导入方
```

## 关键点

- 直接运行 = `"__main__"`（双下划线特殊值）；被导入 = 模块名
- 守卫让「测试代码只在直接运行时执行」成为可能
- 配合 import 副作用理解：被导入时顶层代码照执行，守卫块跳过

## 陷阱

- `"__main__"` 是脚本专属特殊值，`"main"` 是普通模块名（main.py 被导入时的名字），别混
- 看报错栈时用 `__name__` 判断当前文件是被导入还是直接运行
