# 列表推导式

## 是什么

用一行表达式从可迭代对象生成新列表，等价于 JavaScript 的 `map` + `filter` 合体：

```python
[w.upper() for w in words if len(w) > 4]
```

对应 JS：`words.map(w => w.toUpperCase()).filter(w => w.length > 4)`

## 语法

```text
[表达式 for 变量 in 可迭代对象 if 条件]
```

`if 条件` 可省略，省略时只做映射。

## 关键点

- `for` 后面的变量名是占位符，叫什么都行，但表达式和条件里必须用同一个名字
- `len(w) > 4` 是 Python 写法，不要写 `w.length`
