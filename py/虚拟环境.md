# 虚拟环境

## 是什么

虚拟环境是基于某个 Python 解释器创建的隔离运行环境。每个项目可以拥有自己的解释器入口和第三方依赖，避免不同项目互相污染。

`.venv` 是项目内虚拟环境的常用目录名：

```text
.venv/
├── bin/python
└── lib/python3.12/site-packages/
```

`bin/python` 是这个环境的 Python 入口，可能链接或引用创建它的基础解释器；`site-packages` 是第三方依赖的实际安装位置。

使用 uv 时，可以通过下面的命令在虚拟环境中运行 Python，不必手动激活 `.venv`：

```bash
uv run python
```

`.venv` 与操作系统、CPU 架构和 Python 版本有关，而且可以根据项目文件重建，所以通常不提交到 Git。
