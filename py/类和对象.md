# Python 类和对象

## 是什么

类描述一类对象共同的数据和行为，实例是根据类创建出的具体对象。

```python
class User:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"Hello, {self.name}"


user = User("Anna")
user.greet()
```

Python 创建实例时直接调用类，不使用 JavaScript 的 `new`：

```python
user = User("Anna")
```

## `__init__` 与 `self`

`__init__` 是实例初始化入口。创建实例后，Python 会自动调用它完成属性初始化。

```python
def __init__(self, name):
    self.name = name
```

`self` 表示当前实例，作用类似 JavaScript 方法中的 `this`，但 Python 要求在实例方法的形参列表中显式写出。

```python
class User:
    def rename(self, name):
        self.name = name
```

调用方法时不手动传入 `self`：

```python
user.rename("Bob")
```

Python 会自动把 `user` 作为 `self` 传给 `rename()`。

## 实例属性与类属性

```python
class Ticket:
    status = "open"  # 类属性

    def __init__(self, title):
        self.title = title  # 实例属性
```

类属性属于类，实例属性属于某个具体实例。

```python
a = Ticket("Bug A")
b = Ticket("Bug B")
```

这里：

- `Ticket.status` 是类属性。
- `a.title` 和 `b.title` 是各自的实例属性。

## 属性查找与同名遮蔽

实例读取属性时，可以先按这个简化模型理解：

1. 查找实例自己的同名属性。
2. 实例中没有时，再从类中查找。

```python
class Ticket:
    status = "open"

    def close(self):
        self.status = "closed"


a = Ticket()
b = Ticket()

a.close()
```

最终：

```python
a.status       # "closed"
b.status       # "open"
Ticket.status  # "open"
```

`self.status = "closed"` 给 `a` 创建了一个同名实例属性，遮蔽了类属性，并没有修改 `Ticket.status`。

## 类级可变对象会被共享

类属性只有一份。如果把可变对象放在类上，所有未遮蔽该属性的实例会访问同一个对象：

```python
class Team:
    members = []


a = Team()
b = Team()

a.members.append("Anna")

b.members  # ["Anna"]
a.members is b.members  # True
```

需要每个实例独立保存的数据，应在 `__init__` 中创建：

```python
class Team:
    def __init__(self):
        self.members = []
```

这和函数的可变默认参数陷阱属于同一类问题：多个使用者意外共享了同一个可变对象。

## `dataclass`

如果类主要用于保存数据，可以使用 `dataclass` 减少样板代码：

```python
from dataclasses import dataclass


@dataclass
class Ticket:
    title: str
    status: str = "open"
```

可以直接创建实例：

```python
a = Ticket("Bug A")
b = Ticket("Bug B", status="closed")
```

`@dataclass` 会根据字段定义自动生成常用方法，包括：

- `__init__`：初始化字段。
- `__repr__`：生成可读的对象展示。
- `__eq__`：按字段值比较两个同类实例。

```python
Ticket("Bug A") == Ticket("Bug A")  # True
Ticket("Bug A") == Ticket("Bug B")  # False
```

这里的 `title: str`、`status: str` 是类型标注。`dataclass` 会利用这些标注识别字段，但普通 Python 默认不会仅凭标注执行运行时类型校验。

## `default_factory` 创建独立可变字段

可变字段不能直接使用一个共享列表作为默认值：

```python
@dataclass
class Ticket:
    tags: list[str] = []  # 错误
```

应使用 `field(default_factory=...)`：

```python
from dataclasses import dataclass, field


@dataclass
class Ticket:
    title: str
    status: str = "open"
    tags: list[str] = field(default_factory=list)
```

`default_factory=list` 表示每创建一个 `Ticket`，就调用一次 `list()`，为该实例生成独立列表。

```python
a = Ticket("Bug A")
b = Ticket("Bug B")

a.tags.append("urgent")

a.tags  # ["urgent"]
b.tags  # []
a.tags is b.tags  # False
```

它与函数中的 `None` 哨兵写法目标相同：把可变对象的创建推迟到每次创建实例或每次调用时，避免共享状态。

## 普通类与 `dataclass` 的选择

使用普通类：

- 类以行为和状态变化为主。
- 初始化过程需要较多自定义逻辑。
- 需要精确控制对象接口。

使用 `dataclass`：

- 类主要表示一组数据字段。
- 希望自动获得初始化、展示和字段相等比较。
- 适合内部数据传递、配置和简单领域对象。

进入 FastAPI 后还会遇到 Pydantic 模型。它除了描述字段，还承担运行时解析与校验，不能简单等同于 `dataclass`。

## 容易混淆的点

- Python 创建实例不写 `new`。
- 实例方法定义时必须显式写 `self`，调用时不用手动传入。
- `self.attribute = value` 通常是在实例上绑定属性。
- 实例没有同名属性时，才会回退读取类属性。
- 给实例创建同名属性会遮蔽类属性，不等于修改类属性。
- 类级列表、字典等可变对象会被实例共享。
- `dataclass` 的可变字段使用 `field(default_factory=...)`。
- 类型标注默认不等于运行时校验。

## 闭卷自测

```python
from dataclasses import dataclass, field


@dataclass
class Ticket:
    category = "support"
    title: str
    status: str = "open"
    tags: list[str] = field(default_factory=list)

    def close(self):
        self.status = "closed"


a = Ticket("Bug A")
b = Ticket("Bug B")

a.close()
a.tags.append("urgent")
```

1. `a.status`、`b.status` 分别是什么？
2. `a.tags`、`b.tags` 分别是什么？
3. `a.tags is b.tags` 是什么？
4. `a.category`、`b.category` 和 `Ticket.category` 分别来自哪里？
5. 如果执行 `a.category = "incident"`，是否会修改 `Ticket.category`？
