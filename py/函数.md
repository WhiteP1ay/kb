# Python 函数

## 是什么

函数把一段逻辑封装成可重复调用的对象。调用函数时，Python 会先把实参绑定到形参，再执行函数体。

```python
def greet(name, message="Hello"):
    return f"{message}, {name}"


greet("Anna")
greet("Anna", message="Hi")
```

Python 支持按位置传参和按名字传参。默认参数只在调用者没有提供对应参数时生效。

## 参数绑定规则

### 仅限位置参数 `/`

`/` 前的参数只能按位置传递：

```python
def build(kind, /, name):
    return kind, name


build("report", "daily")       # 合法
build("report", name="daily")  # 合法
build(kind="report", name="daily")  # TypeError
```

这里 `kind` 只能按位置传递，`name` 既能按位置传递，也能按关键字传递。

### 仅限关键字参数 `*`

`*` 后的参数只能按名字传递：

```python
def send(message, *, urgent=False):
    return message, urgent


send("restart", urgent=True)  # 合法
send("restart", True)         # TypeError
```

仅限关键字参数可以让调用处直接表达布尔值等参数的含义。

### `*args` 收集剩余位置参数

```python
def pack(name, *values):
    return name, values


pack("task", 1, 2, 3)
# ("task", (1, 2, 3))
```

`values` 是元组。`args` 只是惯用名称，也可以使用其他名字。

### `**kwargs` 收集未匹配的关键字参数

```python
def inspect(name, *, active=True, **options):
    return name, active, options


inspect("task", active=False, color="red")
# ("task", False, {"color": "red"})
```

`active` 已被同名形参接收，不会再进入 `options`。`**options` 只收集没有匹配到明确形参的关键字参数，结果是字典。

## 调用侧的 `*` 和 `**`

函数定义中的 `*args`、`**kwargs` 负责收集；函数调用中的 `*iterable`、`**mapping` 负责展开。

```python
args = ("Python", "backend", "api")
options = {
    "visible": False,
    "owner": "Anna",
}

publish(*args, **options)
```

等价于：

```python
publish(
    "Python",
    "backend",
    "api",
    visible=False,
    owner="Anna",
)
```

如果同一个参数收到两次值，会抛出 `TypeError`：

```python
options = {"visible": False}

publish("Python", visible=True, **options)
# TypeError：visible 被重复绑定
```

## 返回值

没有显式返回值，或者只写 `return`，函数都会返回 `None`：

```python
def stop():
    return


result = stop()
result is None  # True
```

`return a, b` 看起来返回多个值，实际返回的是一个元组：

```python
def analyze():
    return 12, 4.0


result = analyze()
# (12, 4.0)
```

执行 `return` 后，当前函数会立即结束。

## 可变默认参数陷阱

Python 的默认参数在执行 `def`、创建函数时求值一次，不是每次调用都重新求值。

```python
def add(item, bucket=[]):
    bucket.append(item)
    return bucket


a = add("A")
b = add("B")
```

`a` 和 `b` 指向同一个默认列表。第二次调用修改该列表后，两者看到的内容都是：

```python
["A", "B"]
```

这与 JavaScript 默认参数表达式通常在每次调用时重新求值不同。

### 使用 `None` 哨兵

```python
def add(item, bucket=None):
    if bucket is None:
        bucket = []

    bucket.append(item)
    return bucket
```

这里约定 `None` 表示“调用者没有提供列表，请在本次调用中创建新列表”。哨兵不是特殊语法，只是双方约定的特殊信号。

```python
a = add("A")  # 新列表
b = add("B")  # 另一个新列表
```

如果调用者显式传入列表，函数仍然会修改并返回那个列表：

```python
items = [1, 2]
result = add(3, items)

items == [1, 2, 3]
items is result  # True
```

使用 `is None`，不要用 `if not bucket` 代替。后者会把调用者主动传入的空列表也判断为假值。

## 容易混淆的点

- `/` 前的参数仅限位置传递，`*` 后的参数仅限关键字传递。
- `*args` 是元组，`**kwargs` 是字典。
- `**kwargs` 只收集未匹配的关键字参数，不会重复收集已有同名形参。
- 定义侧的 `*`、`**` 负责收集，调用侧的 `*`、`**` 负责展开。
- 同一个参数被显式参数和 `**mapping` 重复传值会抛出 `TypeError`。
- `return a, b` 返回一个元组；没有显式返回值时得到 `None`。
- 可变默认参数会跨调用共享状态；通常使用 `None` 哨兵后在函数内部创建新对象。
- 变量保存的是对象引用，不是调用时的值快照。多个变量指向同一个列表时，原地修改会被所有引用观察到。

```python
    if not items:
        return None

    return head, items, enabled, meta

    "enabled": False,
    "owner": "Anna",
}

result = collect(*args, **options)
```
