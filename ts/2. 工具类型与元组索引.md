# 工具类型与元组索引

## Exclude vs Omit：联合排除 vs 对象裁剪

两者的根本差异在于**操作的类型领域不同**：

| 工具类型 | 作用目标 | 核心语义 | 底层原理 |
| :--- | :--- | :--- | :--- |
| **`Exclude<T, U>`** | **联合类型** (Union) | 从联合类型 `T` 中剔除可以赋值给 `U` 的成员 | 条件分发类型：`T extends U ? never : T` |
| **`Omit<T, K>`** | **对象类型** (Object) | 从对象类型 `T` 中彻底剔除属性键 `K` | `Pick<T, Exclude<keyof T, K>>` |

```typescript
// Exclude：操作联合项
type Status = "pending" | "success" | "failed";
type FinishStatus = Exclude<Status, "pending">;
// 结果: "success" | "failed"

// Omit：操作对象键值
type User = { id: number; name: string; age: number };
type UserWithoutAge = Omit<User, "age">;
// 结果: { id: number; name: string }
```

- **记忆口诀**：`Exclude` 看联合类型里“排除哪几种可能”；`Omit` 看对象类型里“删掉哪几个字段”。
- **底层联动**：`Omit` 本质上就是借助 `Exclude` 先把属性名联合过滤，再通过 `Pick` 重新组装对象。

## 元组转联合类型：T[number]

使用索引访问类型（Indexed Access Type）的特性，通过 `[number]` 提取元组或数组中所有可能的元素类型，自动塌陷合并为联合类型。

```typescript
type HttpMethods = ["GET", "POST", "PUT", "DELETE"];

// 提取所有元素类型并自动去重为联合类型
type Method = HttpMethods[number];
// 结果: "GET" | "POST" | "PUT" | "DELETE"
```

- **实战利器**：配合 `as const` 将只读数组快速推导为字面量联合类型：
  ```typescript
  const roles = ["admin", "editor", "viewer"] as const;
  type Role = (typeof roles)[number];
  // 结果: "admin" | "editor" | "viewer"
  ```
