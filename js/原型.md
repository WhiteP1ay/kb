# 原型

为了避免每 new 一个对象都要重复存储全部属性，所以：
创建一个公共仓库 `prototype 原型`存储共有属性，大家各自只存储独有的属性。

## prototype & \_\_proto\_\_
 
 **`prototype`**（施工图纸 / 模具）只有函数才有。它是给实例准备的公共仓库。

比如：`User.prototype.sayHi = function() {...}`，意思是：“以后通过我 `new` 出来的孩子，都可以来这里用 `sayHi`”。

 **`__proto__`** （寻亲指针）所有对象都有，指向公共仓库。

```ts
const u1 = new User('张三');

// 孩子身上的寻亲指针(__proto__)，精准指向了父亲生他时用的图纸仓库(prototype)
u1.__proto__ === User.prototype; // true！
```

## 原型链

当你在控制台写 `u1.sayHi()` 时，JS 引擎做了什么？

1. 先在 `u1` 自身找有没有 `sayHi`？
    - 没有。
2. 顺着 `u1.__proto__` 找到了 `User.prototype` 仓库，发现里面有 `sayHi`！
    - 找到了，直接执行。

如果还没找到呢？ 那就会继续顺着 `User.prototype.__proto__` 往上找老祖宗的仓库……  
**这种像铁链一样一环套一环、通过 `__proto__` 串起来的查找路线，就叫做「原型链」！**

## 顶层对象

顶层对象是 Object。
u1 自身没有就去找 u1.\_\_proto\_\_，即User.prototype，如果再没有就会去找Object.prototype。
Object.prototype对象的__proto__指向null。这里是绝对尽头。

## Function 与 Object

1. **一切构造函数，本质上都是被 `Function` 创造出来的：**
    - `Object` 是一个构造函数吗？是的（`new Object()`）。
    - 所以：`Object.__proto__ === Function.prototype`。

2. **`Function` 构造函数本身也是函数：**
    - 鸡生蛋蛋生鸡，JS 规定 `Function` 的寻亲指针指向自己的图纸：
    - `Function.__proto__ === Function.prototype`。

3. **但是！`Function.prototype` 这个公共仓库本身是个“对象”：**
    - 既然是对象，它的老祖宗就得归 `Object` 管：
    - `Function.prototype.__proto__ === Object.prototype`。

只要牢记：**所有构造函数的 `__proto__` 都指向 `Function.prototype`；而最终所有的 `.prototype` 仓库，其 `__proto__` 都会汇入 `Object.prototype`，最后归结为 `null`。**


## class 与原型链

```ts
class Person {
  constructor(name) {
    this.name = name;
  }
  sayHello() {
    console.log('hi');
  }
}
```

- `class Person` 本质就是一个**构造函数**。
- 类里面写的方法 `sayHello()`，本质上就是挂在 **`Person.prototype.sayHello`** 上。
- `class Student extends Person` 的继承，底层就是把 `Student.prototype.__proto__` 指向了 `Person.prototype`。

## 手写 instanceOf

```ts
// 核心，b的prototype是靶子，a找自己的__proto__是否与靶子相同，不是则继续往上找
function myInstanceof(a, b) {
  // 1. 基本数据类型直接返回 false
  if (a === null || (typeof a !== 'object' && typeof a !== 'function')) {
  return false;
  }
  
  const target = b.prototype; // 靶子保持不变
  let current = Object.getPrototypeOf(a); // 相当于 a.__proto__

  // 2. 顺着 a 的原型链一直往上爬
  while (current !== null) {
    if (current === target) {
      return true; // 抓到了靶子！
    }
    // 等价于 current = current.__proto__
    current = Object.getPrototypeOf(current); 
  }

  // 3. 爬到了 null 还没抓到 
  return false;
}
```
