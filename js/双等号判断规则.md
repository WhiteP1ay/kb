# == 运算符的判断规则

两边同型比本身，空与未定是爱人（null == undefined）。
布尔遇谁都转数，字符对数数为主。
对象若是见原始，扒层皮来再相见（ToPrimitive）。

## 面试题

#### **1. 为什么 `[] == false` 是 `true`？**

1. 右边是布尔值，先转数字：`[] == 0`
2. 左边是对象，转原始值：`[].toString()` 得到 `""`，变成 `"" == 0`
3. 字符串转数字：`Number("")` 得到 `0`，变成 `0 == 0`
4. 结果为 **`true`**。

#### **2. 为什么 `[] == ![]` 是 `true`？**

1. 注意右边有**逻辑非 `!`**，运算符优先级更高！
2. `![]`：数组是真值（Truthy），取反得到布尔值 `false`。
3. 题目直接变成了：`[] == false`。
4. 按照上一题的步骤，最终结果为 **`true`**。

#### **3. 为什么 `{} == false` 会报语法错误或得 `false`？**

- 如果在浏览器控制台**行首直接输入** `{} == false`：行首的大括号被当成空代码块，剩下 `== false` 会报语法错误（Unexpected token `==`）。
- 如果包裹括号 `({} == false)`：
    1. `false` 转数字：`{} == 0`
    2. `{}` 转原始值：`{}.toString()` 得到 `"[object Object]"`
    3. 变成 `"[object Object]" == 0` →\rightarrow→ `NaN == 0` →\rightarrow→ **`false`**。
