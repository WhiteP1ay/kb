# === 运算符的判断规则

- **类型不同**：直接返回 `false`。
- **类型相同时**：
    - **对象/数组/函数**：比较**内存引用地址**
    - **基本类型**：比较**值本身**。
        - 字符串完全相同 → `true`
        - 布尔值相同 → `true`
        - `null === null` → `true`
        - `undefined === undefined` → `true`
- **两个反直觉的特殊情况（源于 IEEE 754 浮点数规范）**：
    - **`NaN === NaN` → `false`**（规范规定 `NaN` 与任何值都不相等，包括它自己）。
    - **`+0 === -0` → `true`**（在数学和常规逻辑上它们被视作相等）。

## Object.is()

基本与 `===` 一致，修复了两个反直觉的特殊情况。
即 `Object.is(NaN, NaN)` 返回 `true` 
 `Object.is(+0, -0)` 返回 `false`
