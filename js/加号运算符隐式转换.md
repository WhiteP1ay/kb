# 加号运算符的隐式转换规则

规则：
- 任意一边是字符串 → 转字符串拼接；
- 否则尝试转数字。
- 对象 + 数字：先调 valueOf()如果返回的不是原始类型，会再 toString()
- 内置对象只有 Date 是先 toString() 后 valueOf()
- 对象 **`[Symbol.toPrimitive]`** 属性优先级最高。

```js
const obj = {
  [Symbol.toPrimitive](hint) {
    console.log(`hint 是: ${hint}`);
    return 10;
  },
  
  valueOf() { return 20; },
  toString() { return '30'; }
};

+obj; // hint 是: number -> 10（不走 valueOf）
obj + 1; // hint 是: default -> 11（不走 valueOf/toString）
```
## 示例

- `'5' + 3` → `'53'`（字符串优先）
- `true + 1` → `2`（Boolean 转 Number）
- `null + 1` → `1`（null 转 0）
- `undefined + 1` → `NaN`（undefined 转 NaN）

## [ ] + { }

**`[]` 转原始值**：
- 优先尝试 `valueOf()` 返回自身（仍是对象）。
- 接着调用 `toString()`，空数组转为空字符串：`""`。

**`{}` 转原始值**：
- 优先尝试 `valueOf()` 返回自身。
- 接着调用 `toString()`，普通对象返回：`"[object Object]"`。

其中一方是字符串，`+` 执行字符串拼接：`"" + "[object Object]"` → **`'[object Object]'`**。

## { } + [ ]

**`{}` 不会被解析为对象，而是被 JS 引擎解析为「空代码块（Block Statement）」**
所以真正执行的是 `+[]`，即把空数组转换为数字类型。
空数组先调 valueOf 发现还是数组，然后调用 toString，返回空字符串，空字符串转数字得 0。
