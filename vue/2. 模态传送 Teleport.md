# 模态传送 Teleport

将组件的 DOM 结构传送到当前组件挂载点之外的任意指定 DOM 节点（如 `body`），常用于全屏弹窗、模态对话框（Modal）、全局通知（Toast）。

## 核心用法

```vue
<template>
  <button @click="open = true">打开弹窗</button>

  <!-- 将弹窗内容直接传送到 body 标签下，摆脱父级 overflow: hidden 或定位层叠上下文限制 -->
  <Teleport to="body">
    <div v-if="open" class="modal-overlay">
      <div class="modal-content">
        <p>这是一个脱离父级 DOM 的弹窗</p>
        <button @click="open = false">关闭</button>
      </div>
    </div>
  </Teleport>
</template>
```

- **铁律：DOM 节点传送 ≠ 组件逻辑脱离**：
  - Teleport **只改变了渲染出来的 HTML 物理位置**；
  - 它在 Vue 的**虚拟组件树中仍然是当前组件的亲生子组件**。
- **生命周期与上下文**：
  - 父组件销毁卸载时，Teleport 内部传送出去的 DOM 也会被**同步正常销毁**。
  - 上下文注入（`provide / inject`）和事件冒泡依然沿着原本的 Vue 组件树向上查找，完全不受 DOM 物理层级改变的影响。
