# 双向绑定与 defineModel

Vue 3.4+ 引入的终极双向绑定语法糖，彻底消灭了繁琐的 `props` 与 `emit("update:modelValue")` 样板代码。

## 现代写法：defineModel

```vue
<!-- 子组件 CustomInput.vue -->
<script setup>
// 默认双向绑定：内部自动声明 modelValue prop 与 update:modelValue 事件
const model = defineModel()

// 也可以具名双向绑定，如 v-model:title
const title = defineModel("title", { default: "默认标题" })
</script>

<template>
  <input v-model="model" />
</template>
```

```vue
<!-- 父组件 -->
<template>
  <!-- 直接双向绑定，修改子组件时父组件数据自动同步 -->
  <CustomInput v-model="searchText" />
</template>
```

- **心智模型**：`defineModel` 返回的是一个普通的 `ref`。在子组件里直接修改 `model.value = "xxx"`，Vue 底层会自动触发事件通知父组件更新，开发体感与普通本地状态完全一致。
- **自定义修饰符**：支持接收自定义修饰符（如 `v-model.trim`），通过解构 `const [model, modifiers] = defineModel()` 处理。
