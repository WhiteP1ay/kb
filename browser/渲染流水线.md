# 浏览器渲染流水线全流程

## 是什么

渲染本质：render(HTML) → pixels

八个阶段：
解析→样式计算→布局→分层→绘制→分块→光栅化→画

## 关键点

- 主线程：解析 DOM+CSSOM → 样式计算 → Layout 树 → Layer 树 → 绘制指令集
- 合成线程：分块 → 光栅化(转位图) → Draw Quad → 提交 GPU
- transform 动画只走合成线程，不触发 Layout/Paint，性能最高
- 回流(reflow)必触发重绘；重绘不一定触发回流
- 读取 offsetHeight 等会强制同步回流——读写分离避免强制回流
