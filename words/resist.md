# resist

## 音标
/rɪˈzɪst/

## 释义
v. 抵抗，抵制；抗拒

## 例句
The protesters resisted the police.

I can't resist refactoring messy code when I see it. *(自造句)*

## 记忆法

### 词根
> re- (back, against 反对) + sist (站立) → 站在对立面 → 抵抗
