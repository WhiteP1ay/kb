# representative

## 音标
/ˌrɛprɪˈzɛntətɪv/

## 释义
代表（人）

## 例句
The React Foundation will be governed by a board of directors composed of representatives from each major contributor project.

Each major contributor project gets to nominate one representative to the technical committee.

## 记忆法
re(再) + present(呈现) + ative → 替你呈现的人 → 代表

## 同义词
delegate, spokesperson, agent
