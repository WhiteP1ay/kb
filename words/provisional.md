# provisional

## 音标
/prəˈvɪʒənəl/

## 释义
临时的 / 暂定的

## 例句
We have formed a provisional leadership council to determine this structure.

The API is still under a provisional spec — breaking changes are expected before v1.

## 记忆法
pro(前) + vis(看) + ional → 提前看到的 → 临时的。记：先看着办的安排

## 同义词
temporary, interim, tentative
