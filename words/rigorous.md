# rigorous

## 音标
/ˈrɪɡ.ər.əs/

## 释义
adj. 严格的，严密的，缜密的（尤指过程或方法）

## 例句
The paper underwent rigorous peer review before publication.

A rigorous code review catches bugs that linters miss — no shortcuts.

## 记忆法
rigor（严格）+ ous（形容词后缀）= 像僵硬的尺子一样毫不通融 → 严格的，缜密的。

rigor 词根家族（同源拉丁 rigere "变硬"）：
- rigor — 严密，严酷
- **rigorous** — 严格的，缜密的 ← 你在这里
- rigid — 僵硬的，死板的（物理+抽象双关）
- rigidity — 刚性，僵化
- [[rigor-mortis]] — 尸僵（法医学：死后肌肉僵硬）

一根筋通到底：物理僵硬 → 抽象严格。
