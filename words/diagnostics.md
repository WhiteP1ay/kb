# diagnostics

## 音标
/ˌdaɪ.əɡˈnɒs.tɪks/

## 释义
n. （编程语境）诊断信息——编辑器/编译器实时显示的语法错误、类型警告、代码提示等反馈信息。

注：原为 diagnose（诊断）的名词复数形式，在软件开发中特指 IDE 里的错误提示和代码分析结果。源码里 "red squiggles" 就是一种 diagnostic。

## 例句
The blood test is a standard diagnostic for detecting infections.

Ever since the TS compiler rewrite, diagnostics pop up before I even finish typing — it's unreal.

## 记忆法

### 词根
> **dia-**（穿过、彻底）+ **gno-**（知道，PIE 词根 \*gno-）→ 希腊语 diagnōstikos（能分辨的）
>
> 字面义：**"彻底看穿"**——透过表面症状找到根因。
>
> 同词根家族庞大：**diagnosis**（诊断）、**agnostic**（a- 否定 + gno- = 不可知的）、**prognosis**（pro- 预先 + gno- = 预知/预后）、**recognize**（re- 再次 + gno- = 重新认出）。

### 谐音
> —

## 同义词
analysis, troubleshooting, error-checking, code inspection
