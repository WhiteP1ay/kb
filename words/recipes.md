# recipes

## 音标
/ˈrɛsəpi/ (单数 recipe)

## 释义
n. 食谱，烹饪法（做一道菜的步骤清单）

n. 方法，诀窍，配方（达成某个结果的步骤组合，类似中文的"秘方"）

## 例句
I found a great pasta recipe that only takes 15 minutes. (我找到了一个只要15分钟的意面食谱)

This blog post shares some useful recipes for handling async state in React. (这篇博文分享了一些处理React异步状态的好方法)

## 记忆法
发音是"res-uh-pee"，注意拼写里有个隐藏的 c 不发音。和 **receipt**（收据）同源——都来自拉丁语 **recipere**（接收）。想象古时候大夫开处方，开头写 "Recipe..."（拉丁语"请取..."），列出各种药材——跟今天的菜谱列出食材一个逻辑。从一个指令动词变成了名词。

## 同义词
formula（配方）, method（方法）, instructions（说明）, guide（指南）, cookbook（菜谱书）

## 相关单词
receipt（收据—同词根 recipere）, receive（接收—同词根）, [[ingredient]]（食材—同源例句）
