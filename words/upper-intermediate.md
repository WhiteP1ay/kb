# upper-intermediate

## 音标

/ˈʌpər ˌɪntərˈmiːdiət/

## 释义

n./adj. 中高级（语言水平等级，介于 intermediate 和 advanced 之间）

## 例句

I'm currently at an upper-intermediate level in English. （我目前英语水平是中高级）

This course is designed for upper-intermediate learners. （这门课面向中高级学习者）

## 语言水平等级

- beginner → elementary → **pre-intermediate** → **intermediate** → **upper-intermediate** → advanced → proficient

中文俗称：初级 → 初中级 → 中级 → 中高级 → 高级

## 关键点

- 也称 B2（CEFR 欧洲语言共同参考框架标准）
- 能流利讨论大部分话题，但复杂抽象内容仍有困难
