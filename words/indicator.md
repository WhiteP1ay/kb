# indicator

## 音标

/ˈɪndɪˌkeɪtər/

## 释义

**n.** 指标，指示物。用于反映某种状态或趋势的测量数据。

## 例句

- Muscular strength and flexibility are key health indicators.
- CPU usage 和 memory usage 是服务器健康的两个关键 indicator，运维就盯着这俩看。（自造句）

## 记忆法

indicate（指示、表明）+ -or（做某事的人或物）= 用来指示的东西 → 指标。indicate 来自拉丁语 indicare（指出）。

## 同义词

metric, gauge, measure, sign
