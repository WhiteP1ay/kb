# scratch

## 音标
/skrætʃ/

## 释义
v. 抓，挠，刮

n. 划痕，抓痕

**from scratch** — 从零开始，白手起家，从头做起（不用现成的东西，自己一点点来）

## 例句
So you want to build your own AI agent from scratch? (所以你想从零开始自己搭一个AI agent？)

We rewrote the entire auth system from scratch because the old one was a security nightmare. (我们把整个认证系统从零重写了，旧的那个安全问题一团糟)

## 记忆法
from scratch 起源于18世纪的赛跑——比赛开始前在地上用棍子**划一条线**（scratch a line），所有人从那条线起跑，没有任何人占便宜。后来延伸到做饭（from scratch = 从生食材开始，而非买半成品），再泛化成"不用模板、不用框架、纯手写"。build from scratch = 一张白纸开始搭。

## 同义词
from the ground up（从地基开始）, from zero（从零）, from nothing（从无到有）

## 相关单词
scratch card（刮刮卡）, scratch the surface（浅尝辄止）, start over（重新开始）
