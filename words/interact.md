# interact

## 音标

/ˌɪn.tərˈækt/

## 释义

**v.** 相互作用、互动、交流

## 例句

- They interact with our bodies in so many ways.（它们与人体有多种相互作用方式。）
- The frontend and backend interact through REST APIs — when that contract breaks, both sides point fingers.（前后端通过 REST API 交互——合同一破，两边互相甩锅。）

## 记忆法

inter-（在……之间）+ act（行动）→ 在两者之间行动→相互作用。锚点词：interaction（互动）、interactive（交互式的）、interview（面试——两个人之间互相看）。inter- 家族很好记：international（国家间的）、internet（网络间的）。

## 同义词

communicate, engage, interface, cooperate
