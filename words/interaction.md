# interaction

## 音标

/ˌɪntərˈækʃn/

## 释义

**n.** 相互作用；互动；交互

## 例句

- The interaction between the frontend and the API is handled by axios.（前端与 API 的交互由 axios 处理。）
- Social interaction is important for mental health.（社交互动对心理健康很重要。）

## 记忆法

inter-（之间）+ act（行动）→ 在两者之间行动 → 互动。同根：interactive（交互式的）、interview（面试）。
