# therapeutic

## 音标

/ˌθer.əˈpjuː.tɪk/

## 释义

**adj.** 治疗性的、有疗效的

## 例句

- Biohacking of the plants' chemical makeup could create valuable therapeutics.（对植物化学成分的生物改造可催生有价值的治疗药物。）
- Writing unit tests is surprisingly therapeutic — it's the only time code does exactly what you expect.（写单元测试出奇地有疗愈效果——这是代码唯一按你预期运行的时候。）

## 记忆法

来自希腊语 therapeuein（照料、治疗）。锚点词：therapy（治疗），therapist（治疗师）。注意发音：ther-a-PEU-tic，重音在 peu 上。词根 thera- 跟"照料"有关，和"theory"没有关系。

## 同义词

curative, healing, remedial, medicinal
