# potentially

## 音标

/pəˈtɛnʃəli/ (美)

## 释义

**adv.** 可能地，潜在地

## 例句

- This discovery could potentially change how we treat cancer.
- The new AI model is potentially game-changing for code review tools.（自造句）

## 记忆法

potential（潜力/潜在的）+ -ly（副词后缀）。拉丁词根 potentia = 力量/能力 → potential 是"有能力但尚未实现" → potentially = 潜在地。锚点词：potential（潜力/潜在的）。

## 同义词

possibly, maybe, conceivably
