# characteristics

## 音标
/ˌkærəktəˈrɪstɪks/

## 释义
n. (复数) 特征，特点，特性（使某人或某物区别于其他的显著属性）

sing. **characteristic** — adj. 典型的，特有的

## 例句
A pure function is a function with the following characteristics: it always returns the same output for the same input, and it has no side effects. (纯函数具备以下特征：相同输入永远返回相同输出，且没有任何副作用)

One of the defining characteristics of a senior engineer is knowing what NOT to build. (高级工程师的一个标志性特征，是知道什么东西不该做)

## 记忆法
来自希腊语 **kharaktēr**（刻痕、标记）→ 在某个东西上做记号 → 那个记号就是它的"特征"。跟 character（性格/角色）同根——一个人的 character 就是他的内在"特征"，一个事物的 characteristics 是它的外在"特征"。词根一致，记一个就记住俩。

## 同义词
traits（特质）, features（特征）, attributes（属性）, qualities（品质）, properties（属性）, hallmarks（标志）

## 相关单词
character（性格/角色）, characterize（描述特征）, characteristic（单数形式/形容词）, [[-istic]]（后缀）
