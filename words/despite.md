# despite

## 音标

/dɪˈspaɪt/

## 释义

**prep.** 尽管、虽然（= in spite of）

## 例句

- Despite the challenges, scientists are rushing to understand the implications of Arctic warming.
- Despite three code reviews, the null pointer exception still made it to production — turns out everyone skimmed the same file.（自造句）

## 记忆法

despite = in spite of。spite 是"怨恨、恶意"，despite 原意是"蔑视"→ 引申为"无视/不顾"→"尽管有 X"。可以这样记：despite the challenges = 蔑视这些挑战，不管它 = 尽管有挑战。

**语法坑**：despite 后面只能接名词/动名词，不能直接加句子。
- ✓ despite the rain
- ✓ despite being tired
- ✗ despite it was raining → 改成 despite the fact that it was raining / although it was raining

## 同义词

in spite of, regardless of, notwithstanding
