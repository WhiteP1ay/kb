# 一般将来时 (Simple Future)

## 结构

两种主要形式：

### will + 动词原形

```
主语 + will + 动词原形
否定: will not / won't + 动词原形
疑问: Will + 主语 + 动词原形?
```

### be going to + 动词原形

```
主语 + am/is/are + going to + 动词原形
否定: am/is/are + not + going to + 动词原形
疑问: Am/Is/Are + 主语 + going to + 动词原形?
```

### 区别

| 场景 | will | be going to |
|------|------|-------------|
| 说话时才做的临时决定 | ✅ I'll fix it now. | ❌ |
| 事先计划好的事 | ❌ | ✅ I'm going to refactor next sprint. |
| 基于证据的预测 | ❌ | ✅ The server is going to crash — CPU 99%. |
| 一般性预测/猜测 | ✅ I think it will rain. | ✅ (口语也接受) |
| 承诺/威胁/请求 | ✅ I'll have the PR ready by 5pm. | ❌ |

简单记：will 偏"临时起意 + 承诺"，be going to 偏"有计划 + 有迹象"。

## 用法

### 1. 预测未来 (Prediction)

will 用于一般性预测，be going to 用于有证据的预测。

The model will probably converge after another 50 epochs — just a gut feeling.
(一般猜测：我感觉再跑 50 轮应该能收敛)

Look at the loss curve — it's going to overfit if we don't add dropout.
(有证据的预测：看这 loss 曲线走势，不加 dropout 肯定过拟合)

### 2. 计划 vs 临时决定 (Plan vs. Spontaneous Decision)

be going to 表示事先计划好的事，will 表示说话当下才做的决定。

We're going to migrate from REST to GraphQL in Q3. (计划已久)

Oh, the CI is red — I'll check the logs right now. (临时决定)

### 3. 承诺与请求 (Promise & Request)

will 用于承诺、威胁、主动提出帮忙、请求。

I'll get this hotfix deployed before the standup. (承诺)

Will you review my PR when you get a chance? (请求)

### 4. 不可避免的事 (Inevitable)

be going to 表示事态已经很明显、注定要发生。

The disk is at 97% — this node is going to die tonight if nobody cleans up.

## 例句

I'll push the fix to staging as soon as the tests pass — give me five minutes.
(临时决定 + 承诺：测试一过我就推到 staging，等我五分钟)

We're going to rewrite the auth module because every new hire gets confused by the current flow.
(事先计划：我们要重写认证模块，每个新人进来都被现有流程搞晕)

Some day AI is going to write all the boilerplate and we'll just review the logic.
(基于趋势的预测 + 一般预测：总有一天 AI 会写掉所有样板代码，我们只审查逻辑)

## 关键词/标志词

tomorrow, next week / next month / next year, soon, in the future, in 2027, later, someday, one day, tonight, this weekend

遇到这些时间状语，大概率是一般将来时。
