# 过去进行时 (Past Continuous)

## 结构

### 肯定句
主语 + was/were + 动词-ing + 其他

| 人称 | 结构 | 示例 |
|------|------|------|
| I / He / She / It | was + V-ing | I was debugging at 3 AM. |
| You / We / They | were + V-ing | They were running the tests. |

### 否定句
主语 + was not (wasn't) / were not (weren't) + 动词-ing + 其他

```
I wasn't paying attention during the code review.
The server wasn't responding when I checked the logs.
```

> 注意：否定句只是把 was/were 变成 wasn't/weren't，动词保持 -ing 形式不变。

### 疑问句
Was / Were + 主语 + 动词-ing + 其他？

```
Were you still compiling when the power went out?
Was the CI pipeline still running at 6 PM?
```

## 用法

1. 过去某个具体时刻正在进行的动作
   强调在过去某一个精确的时间点，动作"正在进行中"，尚未完成。常见于描述某个特定时刻的状态。
   ```
   At 10 PM last night, I was still fixing a null pointer exception.
   Yesterday at 3 PM, the server was experiencing high CPU usage.
   ```

2. when 引导的句式中，与一般过去时配合使用
   when 后面用一般过去时表示"突然发生的事"，主句用过去进行时表示"背景中正在进行的动作"。这是一个非常高频的句型。
   ```
   I was deploying to prod when the database migration failed.
   She was writing documentation when the CTO walked in and asked about the timeline.
   ```

3. while 引导的句式中，两个动作同时进行
   while 后面用过去进行时，表示两个动作在过去同时持续发生。while 后面必须跟延续性动作，不能是瞬间动作。
   ```
   While I was refactoring the auth module, my coworker was rewriting the frontend in a new framework.
   The linter was running while I was writing new tests.
   ```

   > 对比：when 后面常跟瞬间动作（一般过去时），while 后面跟持续动作（过去进行时）。

4. 描述过去一段时间内的背景状态
   不一定是精确的时间点，而是一段"背景时间"，为另一个事件提供场景铺垫。
   ```
   In 2020, everyone was rushing to build remote collaboration tools.
   During the outage, the on-call team was scrambling to restore service.
   ```

## 例句

```
At midnight I was still refactoring the legacy codebase, and my brain was running on coffee and regret.

While the model was training on 8 GPUs, I was nervously watching the loss curve hoping it wouldn't diverge.

The intern wasn't listening during standup because he was still thinking about the merge conflict from hell.
```

## 关键词/标志词

以下时间状语和连词经常与过去进行时搭配：

- at that time / at that moment (那时)
- at 3 PM yesterday / at midnight last night (过去的具体时刻)
- when ... (当……的时候，后跟一般过去时的瞬间动作)
- while ... (当……的时候，后跟过去进行时的持续动作)
- as ... (随着……，类似 while)
- all morning / all day yesterday / the whole evening (过去整个时间段)
- during ... (在……期间)
