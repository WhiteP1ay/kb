# 过去将来时 (Past Future)

## 结构

两种主要形式：

### would + 动词原形

```
主语 + would + 动词原形
否定: would not / wouldn't + 动词原形
疑问: Would + 主语 + 动词原形?
```

### was/were going to + 动词原形

```
主语 + was/were + going to + 动词原形
否定: was/were + not + going to + 动词原形
疑问: Was/Were + 主语 + going to + 动词原形?
```

### 区别

| 场景 | would | was/were going to |
|------|-------|-------------------|
| 间接引语中转述 will | ✅ He said he would come. | ✅ He said he was going to come. |
| 过去的计划（未实现） | ❌ | ✅ I was going to refactor it, but I got pulled into a meeting. |
| 宾语从句（主句过去时） | ✅ I knew the bug would resurface. | ✅ I knew the bug was going to resurface. |
| 过去的意愿/拒绝 | ✅ The server wouldn't start. | ❌ |

简单记：would 更通用，was/were going to 强调"当时本来打算做但未必做了"。

## 用法

### 1. 宾语从句中的将来（核心用法）

当主句动词是过去时，从句中原本的 will 要变成 would。这是最常遇到的场景。

The PM promised the feature would ship by Friday — it's now Sunday.
(PM 承诺周五上线，现在都周日了)

I thought the migration would take an hour, but we're still running it.
(我以为迁移一小时搞定，结果现在还在跑)

### 2. 间接引语中转述"将来"

把别人说过的话转述出来，原话是将来时，转述后变成过去将来时。

"Our team will handle the incident." → She said their team would handle the incident.

"The API is going to break in the next release." → He warned that the API was going to break in the next release.

### 3. 过去计划做但未做的事

was/were going to 表示"当时本来打算做，但没做成"。程序员日常高频场景。

I was going to write unit tests yesterday, but production caught fire.
(昨天本来要写单元测试的，结果线上炸了)

We were going to deprecate that endpoint in v2, but three internal tools still depend on it.
(本来打算 v2 废弃那个接口，结果还有三个内部工具依赖它)

### 4. 过去的意愿或拒绝 (would)

would 可以表示主语在过去某个时刻"愿意"或"不肯"做某事，尤其否定形式表示"死活不"。

The server wouldn't start after the kernel update — turns out the init script was broken.
(内核更新后服务器死活起不来，结果发现是 init 脚本坏了)

I asked DevOps to increase the disk quota, but they wouldn't budge.
(我让运维加磁盘配额，他们死活不松口)

### 5. 过去习惯性动作 (would)

would 还可以表示过去经常做的事（"过去总会……"），类似 used to，但只能用于动作，不能用于状态。

Every time I pushed to main without a review, the senior dev would ping me within 30 seconds.
(每次我不 review 就推到 main，老大哥 30 秒内必 ping 我)

## 例句

He said the API would be stable by Q3, but here we are in Q4 debugging CORS errors at 2 AM.
(他说 Q3 接口就稳定了，结果 Q4 凌晨两点我们还在修 CORS)

I was going to migrate the database over the weekend, then I remembered it's a holiday and nobody would be on call if things went sideways.
(本来打算周末迁移数据库，然后想起来是假期——翻车了没人值班)

Every sprint, the intern would ask why we still use Jenkins, and every sprint, we would say "tech debt, next quarter."
(每个 sprint 实习生都问为什么还在用 Jenkins，每个 sprint 我们都答"技术债，下季度搞")

## 关键词/标志词

过去将来时通常不出现在独立句子中，而是嵌套在以下语境里：

- 主句动词为过去时的宾语从句：said, told, thought, knew, promised, warned, realized, expected, believed, assumed ...
- 间接引语标志：主句是 He said / She told me / They mentioned 等
- 与过去时间呼应的时间状语：the next day, the following week, the following month, the coming weekend, later that year
- 计划未实现的暗示：was/were going to ... but ...

注意：过去将来时没有独立的"时间标志词"——它依赖的是主句的过去时态。判断标准是：主句是过去时 + 从句表达将来含义。
