# 现在进行时 (Present Continuous)

## 结构

| 句型 | 结构 | 示例 |
|------|------|------|
| 肯定句 | 主语 + am/is/are + V-ing | I am debugging the code. |
| 否定句 | 主语 + am/is/are + not + V-ing | The server is not responding. |
| 一般疑问句 | Am/Is/Are + 主语 + V-ing? | Are you pushing to production? |
| 特殊疑问句 | Wh- + am/is/are + 主语 + V-ing? | What are you working on right now? |

动词-ing 变化规则：

- 一般直接加 -ing：work → working, deploy → deploying
- 以不发音 e 结尾，去 e 加 -ing：write → writing, compile → compiling
- 重读闭音节，双写末尾辅音加 -ing：run → running, commit → committing
- 以 ie 结尾，变 ie 为 y 加 -ing：die → dying, lie → lying

## 用法

### 1. 表示此刻正在进行或发生的动作

常见于对话的开场白，强调"此时此刻我正在做什么"。

> I am writing unit tests for the new API endpoint right now. (我正在给新的 API 接口写单元测试。)

> The CI pipeline is building the Docker image. (CI 流水线正在构建 Docker 镜像。)

### 2. 表示现阶段持续进行但此刻不一定正在做的事

动作在一段时间内断断续续发生，比如一个迭代周期、一个项目阶段。

> I am refactoring the legacy authentication module this sprint. (这个 sprint 我在重构老旧的认证模块。——说话的时候可能正在开会，并不在写代码。)

> Our team is migrating from REST to GraphQL. (我们团队正在从 REST 迁移到 GraphQL。——这是几周甚至几个月的项目。)

### 3. 表示即将发生的安排好的动作（将来含义）

用于已经计划好、通常时间确定的事情。

> The VP of engineering is joining the standup tomorrow morning. (工程 VP 明天早上来参加站会。)

> We are launching the new feature next Monday. (我们下周一上线新功能。)

### 4. 与 always / constantly 连用，表示反复发生的动作（带有情绪色彩）

表达抱怨、厌烦或者夸张的赞扬。

> He is always pushing directly to main without review. (他老是直接推到 main 分支，也不 review。——抱怨)

> Their ChatGPT wrapper is constantly hitting rate limits. (他们的 ChatGPT 套壳老是触发速率限制。——吐槽)

### 不能用现在进行时的动词

以下动词通常不用进行时态，即使描述的是此刻的状态：

| 类别 | 例词 | 典型错误 |
|------|------|----------|
| 感官 | see, hear, smell | I'm seeing a bug. → I see a bug. |
| 思维/认知 | know, believe, understand, remember, forget | I'm not understanding the logic. → I don't understand the logic. |
| 情感/态度 | like, love, hate, want, need, prefer | The PM is wanting a hotfix. → The PM wants a hotfix. |
| 所属/关系 | have(拥有), belong, own, contain, depend | The service is depending on Redis. → The service depends on Redis. |

> 例外：当这些动词表示主动的、有意识的行为而非状态时，可以用进行时。例如 I'm having lunch (我在吃午饭——have 不表示"拥有")，I'm seeing the logs now (我正在看日志——see 表示"查看"而非"看见")。

## 例句

> The backend is crashing every time we run the migration script, so I'm rolling back the database now. (每次跑迁移脚本后端就崩，所以我现在正在回滚数据库。)

> My terminal is currently compiling the Rust project — it's been running for 10 minutes. (我的终端正在编译那个 Rust 项目——已经跑了十分钟了。)

> What are you looking at? The monitoring dashboard just went all red. (你在看什么？监控面板刚全红了。)

## 关键词/标志词

now, right now, at the moment, currently, Look!, Listen!, still, these days, this week/month, always (抱怨)

## 相关时态

- [[simple-present]] — 一般现在时：表示习惯、客观事实（The server starts at 9 AM every day.）
- [[simple-future]] — 一般将来时：与现在进行时表将来的区别在于计划性（I'll fix it. vs I'm fixing it tomorrow.）
- [[past-continuous]] — 过去进行时：将时间轴移到了过去（I was deploying when the outage happened.）
- [[present-perfect]] — 现在完成时：强调动作对现在的结果或持续性（I have been debugging since morning.）
