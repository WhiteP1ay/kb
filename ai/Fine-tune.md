# Fine-tune（微调）

## 是什么

拿特定数据继续训练、调整模型权重，让它擅长某领域或某种行为模式。前端类比：fork 通用组件库源码，改成公司风格，重新 build。

## 关键点

- 改的是模型本身的权重（几十亿浮点数）
- 治「不会用那个姿势说」：稳定行为模式、推理风格、领域判断力的内化
- 轻量方法 LoRA / QLoRA 只训少量参数

## 陷阱

- 输出格式是 prompt 的活，不必 fine-tune（杀鸡用牛刀）
- 权重是黑盒，改完没法像 review 代码那样 diff
- 和 RAG 别混：fine-tune 改模型，RAG 改输入
