软件开发正在从创作性工作变成狗屁工作。

## 丧失心流

之前开发软件很像艺术创作，会让开发者进入心流——一头扎进去，等抬起头经常已经是凌晨。

代码里藏着设计模式，藏着开发者的小巧思。通过精密设计完成一个复杂需求，那种成就感是实打实的。

但很可惜，现在没人这么写代码了。

心流状态的消失不是小事。人脑有个区域叫默认模式网络，负责回忆过去和内耗未来。失眠时闭上眼就是负面回忆，陷入焦虑或抑郁，很大程度上是默认模式网络太兴奋。心流会抑制它，带来内心平静。

所以心流少了，意味着焦虑和内耗变多了。

解法是有意识地制造心流：冥想 / 古法编程 / 写文章 / 画画 / 骑摩托。这些事的共同点是让大脑被一件重要的事占据，没空跑去想别的。比如骑摩托——在公路上走神搞不好就死了，大脑被迫专注。这不是段子，有科学研究证明骑摩托显著降低抑郁。

## 不值钱的代码

代码正变得极其廉价。随便什么人借助 AI 十分钟生成一份 HTML，画面精美，就能开始吹这套东西能解决什么、降低多少成本。

但那套页面背后，数据持久化、用户身份验证——基本的东西都没做。

老板不管这些。老板只知道产品经理都能轻易掏出软件了，程序员更不值钱了。工资再砍砍，工作量再加加。至于优雅的设计、封装、复用性——更没人在乎。

曾经 talk is cheap, show me your code。现在 code is cheap, show me your HTML。

换个角度想：架构能力越来越值钱。愚蠢的公司和低水平开发者抱团等死，高水平开发者和有实力的企业聚在一起越来越强。

但在国内（或者英语水平不够的情况下），还是不建议死磕技术深度。转管理远好于做技术专家。技术专家本质是对自己的异化——像蚁后只负责繁衍，但蚁后有一群工蚁保护供养它。而我们这里没有组织会保护技术专家。

## 对 Claude Code 二次包装

很多传统软件功能变成了对 Claude Code 的二次封装。

比如电脑垃圾清理。传统做法需要开发者有垃圾清理经验加脚本编写能力，把二者打包成清理软件高价卖出。AI 时代同样场景：给 agent 极高权限，让它去 GitHub 读类似开源项目，学习别人怎么清理电脑垃圾，总结成 skill。

电脑清理软件的开发迟早变得毫无意义。唯一的意义是给不会用 Claude Code 的小白包一层糖——做个美观的一键清理按钮。

很多软件开发工作正在变成狗屁工作。本质上都是做美观按钮，一键给 Claude Code 发消息。

但 Claude Code 这类工具从开发终端走出来面向大众，只是时间问题。Codex 改名 ChatGPT 就是证据。
